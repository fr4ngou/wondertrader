# HPR兼容Host

内部私有制品，基线为Host `0.1.0a22+mdphttp.2`及已安装的常驻诊断overlay，精确依赖原Agent `0.1.0a12+marketdaily.4`。

只合入合法控制拒绝的持久收束、原Future退休保护、关闭核原Journal的直接前置，以及固定枚举诊断。交易源码沿原基线保留，不引入主干的UC、SDKReturn、HTTP-retention或新等待时钟实现。原QMT Agent与策略正文保持原字节。

源码、基线wheel及逐文件身份由上级`SOURCE-IDENTITY.json`固定；正常Flit wheel从本目录构建。版本和依赖由本目录pyproject声明，构建不读取现场目录，也不修改运行实例。工程验收不授真实QMT或发布资格。
