- 唯一策略使用真实自然行情完成计算及目标执行；模拟券商下单、查询、成交或撤单与原订单/持仓展示沿标准入口核实。
- 已下载行情可由WT原生存储读取，日线及分钟持续更新与原生采集接通；缺数和读取失败保持不同业务结果。

- 日常同一入口启动、停止、重启保留原账，观衡自动接收当前代；所需运行依赖、回退及操作手册完整。
- 已合入、无运行依赖的多余工作树及重复可重建产物完成可追溯清理，当前数据、原件和未合入成果保留。
