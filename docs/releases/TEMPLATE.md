# 版本与发布主题

状态：candidate / deployed / verified / rolled-back / blocked。目标环境、授权引用、操作者及时间：待填写。

## 发布身份

源提交/差异摘要、构建工具链、依赖、制品和哈希、配置版本、上一运行版本、关联规格与审查证据。

原生组件补充上游基线、逐文件清单、SDK/ABI、状态/协议模式、实例工作目录及实际加载文件；容器组件补充镜像 digest。不同组件的兼容组合与期望/实际身份分别记录。

## 预检与步骤

列出真实环境命令、兼容性、状态保护、启停顺序、在途处理和停止条件；逐项记录实际结果。

## 发布后验真

记录实际加载身份、依赖、用户入口、真实核心数据、关键操作及正常/空/异常/恢复结果，链接证据。

日志：组件/路径、启动后检查区间、是否实际落盘、ERROR/WARN/退出码、处置与未覆盖项。数据/策略变更补逐角色输入覆盖、有效计算和无交易原因；空stderr或其他标的成交不能代替。

影响策略页时，填写[观衡策略页交付验收](../runbooks/release.md#观衡策略页交付验收)各项结果，附正式页面及来源证据，分别记录部署、执行器、账户与策略页验收结论。

## 回滚与结论

旧版可读性、回滚命令及副作用处理；记录是否执行、恢复验真、观察窗口、剩余风险和最终授权状态。
