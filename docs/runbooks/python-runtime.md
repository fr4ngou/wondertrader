# 终端外 Python 运行时维护

类型：运行手册。适用范围：WT辅助进程、券商外部Host、观衡服务和自动化验收的Python环境。QMT内置策略的解释器及受限调用由终端版本管理。

## 固定解释器

长期运行和完整验收使用独立管理的Windows x64 CPython目录。当前角色安装器接受CPython 3.12及显式uv工具；具体patch版本、解释器和DLL摘要、许可证与标准库文件清单记录在工具来源收据中。应用的依赖版本继续取各角色wheel及精确锁。

自动更新的开发工具缓存属于可变输入。将其作为来源时，先完整复制到独立的新目录，核对来源复制前后及目标文件摘要，再实际核对版本、64位、`sys.base_prefix`、`sys._base_executable`和pip。来源在复制期间变化时保留失败目录，以新目录重新准备。固定目录的后续更新采用另一个新版本目录。

解释器目录保留完整运行文件、标准库、许可证及来源记录。通过venv或已安装角色验证实际基础解释器路径，避免只固定一个启动程序而继续引用外部可变目录。固定工具目录不承载业务数据、账户凭据或运行状态。

## 安装与验收

沿[系统离线安装](system-installation.md)将固定解释器作为显式`--python`输入，从已发布wheel及精确锁安装到新的角色目录。安装后核对pip check、RECORD、模块归属及运行收据的`base_executable`和摘要；实际进程从解析后的角色入口启动。

完整验证期间固定所用工具和产品字节。构建工具只参与准备阶段时，归档其当时来源和摘要；实际运行仍需基础解释器、DLL及标准库保持。后台验收由受管命令会话和原进程owner托管，界面自动化会话只承担界面操作。

## 更新及恢复

基础解释器文件变化后，旧收据继续描述原验收时点。先停止给新环境沿用旧身份，将变化单列；使用同一固定产品wheel、精确锁和新的固定解释器并排重建环境。按影响复核导入、只读连接、主要业务及关闭恢复，不把环境变化归为策略或原生框架故障。

已有运行实例保留其配置、数据和原环境。新候选通过验证后，按[发布规范](release.md)处理实际切换及回退；解释器准备和安装操作本身不切换实例、不重发未知委托。
