当前前端为React、TypeScript、Vite，已有TanStack Query/Table、ECharts和Lucide；没有安装完整外观组件库。可保留领域接口、查询缓存、表格及图表运行能力，再统一视觉与交互，不重写整套前端。

## 用户八图审阅

本轮依据为用户明确提供的八张截图，未将截图观察扩大为当前浏览器DOM、完整辅助技术或交互验收。

1. 搜索：只接受完整代码/交易所，缺少匹配候选。应提供名称、拼音和前缀检索，选中后统一证券身份。
2. 基准：上证线提前结束，指标线仍继续。需要核源数据和日期覆盖，图表保持真实缺口。
3. 数字：tooltip长金额难读，单位和精度不统一。采用中文量级与精确值查看。
4. 历史：选择半年仅少量尾部记录，大片空轴掩盖实际覆盖；四组指标缺少上方上证基准。需要补数据并让日期/覆盖可见。
5. 广度：参考图使用共享日期的上下分图，提供RANA/MSI、T2108、Breadth Thrust及涨跌差；本轮再纳入用户要求的TRIN，减少在多个菜单寻找指标的成本。
6. 报告：目录读取失败只有重试提示。应区分配置、空目录和实际读取异常，并接入已有正式归档。
7. 策略：唯一策略符合保留范围，当前页只有简介，缺实际财务、持仓、运行及收益。应把简介降为次要信息，呈现当前真实数据及其口径。
8. 状态：只展示账户实例，行情未配置。当前部署事实确有遗漏连接，不能靠换文案掩盖缺少接线；多实例状态需分别消费。

共性问题为大字号标题、巨幅空白、多层圆角/阴影、重复技术说明与不统一的默认按钮。新方案采用14—16px中文正文、小标题、对齐数字、轻分隔，图表及数据优先。颜色同时配文字/线型，键盘焦点和对比度需在实现后验证；截图不足以证明无障碍合规。

## 视觉方案范围

使用Product Design的截图审阅、get-context及ideate流程；用户与目标已明确，直接提供三张独立1440×1024桌面图。每张以市场广度为主工作区，保留导航、证券搜索、日期和数据时间；上方上证，下方完整指标分组。当前日期锚点2026-11-01，示意交易数据日期至2026-10-30，标识设计示意，禁止把示意点写入运行数据。

三方向分别探索浅色紧凑控制台、深色图表工作台、浅色分析工作簿的层级与布局。最终编号按生成图片实际展示顺序确定；用户选定后进行全局UI实现。后台与现有页面功能修复继续，不受视觉等待影响。当前运行18120及WT采集保持。
