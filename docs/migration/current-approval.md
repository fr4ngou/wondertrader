## 已批准的一项决策：CORE-004

用户已批准保留 `src/WtCore/ParserAdapter.cpp` 构造函数的 `_check_time(false)` 初始化。当前实际文件相对上游仅这一行行为变化，以及文件末尾换行；确认范围是初始化这一行及其必要回归。该差异已在先前工作区存在，现纳入已批准候选，其他框架差异继续冻结。

原样 `initExt` 接收已创建行情插件，没有配置读取步骤，构造函数也未给该成员赋值；handleQuote 会读取它。当前受管行情接入使用此路径，保留该路径进入最终候选需要确定的初值。普通配置 init 缺省值已经是 false，并在注册插件前用配置覆盖。

原样和现有修改版的隔离对照已执行：普通 init 的缺省/false/true 行为一致；原 initExt 的对象字节保留预填内容，修改版将其设为零。具体探针方法与辅助库限制见复核记录，尚未声称真实来源联调完成。

| 事项 | 具体范围 |
|---|---|
| 修改位置 | `src/WtCore/ParserAdapter.cpp::ParserAdapter` 的 `_check_time(false)` |
| 行为 | 使外部初始化路径默认关闭“未来超前一小时”的时间过滤；普通配置继续覆盖默认值 |
| 架构及 ABI | 构造赋值，不新增字段、方法、类布局或线程，不改变引擎和执行架构 |
| 风险 | 原外部路径行为未确定，确定为 false 后需要接入方按来源契约验证时间；普通配置 true 仍启用过滤 |
| 原接口替代 | 自有行情插件改走普通工厂/config init。原加载路径已用测试插件验证；真实 QMT 工厂端点注入仍需接通 |
| 后续验证 | 最终候选重跑 initExt、普通配置三组、实际工厂加载与受管行情调用链；保持时间/新鲜度校验职责 |
| 回滚条件 | 先将所有相关消费者切到已验普通 init，再撤回这一行并重建；保留 initExt 时不能依赖未初始化值 |

执行决定：保留这一行并验证原配置及外部初始化路径；其余差异的保留、修改或撤回须另行明确范围并获得批准。
