# 机构配置与债券重估观察

类型：模块接口正文。适用范围：IMO-R24的三类机构披露及原基金样本债券重估。公开数据生产归观察更新owner；账户、策略和WT运行各自保持原职责。要求及验收沿[唯一规格](../specs/independent-market-observation.md#imo-r24-机构披露及原债券重估输入持续生产)。

| 数据集 | 数值所有者与口径 | 单位、时间与缺失 |
|---|---|---|
| `bond.custody` | 人民银行金融市场运行月报的全市场债券托管余额 | 万亿元；date为月末，available_at为官网公布日；未披露月份留空 |
| `holdings_wealth` | 理财登记托管中心市场报告，直接债券和同业存单分别占投资资产 | 百分数；两项之和明确为舍入分项相加，不改称精确正文值；报告期与公布日分列 |
| `holdings_broker` | 中信证券合并半年/年报附注8，交易性金融资产的公允价值合计列 | 金额人民币元；两种比例分别为债券/同表总额及债券/(债券+股票)，百分数；不代表全行业或完整自营组合 |
| `source.chinabond_wealth` | 中债-新综合指数，财富CFZS、总值00；原公开POST接口 | 指数点；毫秒时间戳转上海日期，历史首次可知时刻未知 |
| `bond.mtm45` | 原基金季度配置加股债指数重估，45自然日可用为既有假定 | 百分数；原中证全指价格及中债财富指数按季度共同基准日求比值；真实日持仓及当时可得资格未知 |

`institution_reports`拥有报告目录、身份、正文、日期、单位和分母解释；原Fetcher持有HTTP、字节归档和统一截止。原refresh持有合并、资产谱系和CAS。公开报告采用固定主机与目录；财报按证券代码和机构身份核对，使用六列表的公允价值合计，不以成本列或母公司表替代。PDF按字节、页数、对象和文本容量读取，每页检查原截止；图像和嵌入对象不执行。

同一期财报可出现在年报及后继半年报比较列。本次窗口内采用较晚公布报告的原数值，同一公布日冲突拒绝；available_at表示选中报告的公布日，最早可知时刻仍未认证。旧期末行保持。季度季报只提供交易性资产总额时，不能与半年报债券分子混用。

`bond_mtm`沿原季度选择及浮点运算次序，只追加旧尾日之后的股债共同观察日；旧模型原字段保持。新增模型行记录anchor_period、anchor_date、model_eligible_date、bond_index_value、bond_index_base、stock_index_base。三个日期分别是季度末、共同基准日和季度末加45天；三个指数数值均为指数点，所属源与日期沿字段中文定义。统一Parquet分区使旧行新增列为空，表示旧归档未保存这些说明，原数值不回填或重算。

模型源表、基金配置分区及原价格父对象纳入同一谱系。季度内不交易、现金和其他资产名义不变、指数代表持仓收益仍是原模型假设。新原生指数保留来源三位小数；旧研究CSV部分价格只有两位小数，复算核证使用原输入，续接使用当前已准入原值，不为拟合旧曲线舍入新源。
