# 服务商接入

类型：模块说明。所有者角色：接入维护者。状态：通用接口与现有插件源码已存在；具体服务商资格按独立证据登记。

## 职责与入口

将外部行情、账户与交易 API 映射为框架接口，声明 SDK、权限、身份、时间、单位和失败语义。行情与交易能力独立登记。

- 行情接口：[IParserApi](../../src/Includes/IParserApi.h)，由 Parser 插件实现并经 SPI 提供行情。
- 交易接口：[ITraderApi](../../src/Includes/ITraderApi.h)，由 Trader 插件实现查询、委托和回报。
- 工程布局参考：[ParserXTP](../../src/ParserXTP/CMakeLists.txt)、[TraderXTP](../../src/TraderXTP/CMakeLists.txt)。具体依赖以工程和来源记录为准。
- 终端侧受限读取：[QMT终端读取源](qmt-terminal-source.md)，通过签名HTTP向原生插件交付值，源码及安装制品由本仓库拥有。

## 契约与生命周期

接入规格必须列出连接、认证、订阅/查询、断开、重新绑定和释放顺序；规定 SDK 回调线程、框架调用线程和对象所有权。SPI 回调中的对象保留、拷贝与释放遵循接口及引用计数实现。

字段转换集中实现，未知枚举、缺失时间、单位不确定或身份不符以明确错误返回。账户登录、通道连接和业务就绪分别报告；调用返回、持久受理和柜台结果分别描述。

## 验证与恢复

接口测试覆盖转换、重复回调、查询结束/失败、超时、断线、旧会话和卸载。SDK 集成和实际账户资格分别记录。使用隔离替身验证副作用窗口；具有真实副作用的验证按授权执行。

运行支持条件见[构建手册](../runbooks/build.md)，执行状态见[交易执行](execution.md)，跨模块要求见[验证规范](../development/verification.md)。
