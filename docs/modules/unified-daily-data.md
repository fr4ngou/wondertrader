# WT统一日线与证券资料

类型：模块说明。状态：初始股票角色、七指标及独立API已完成正式部署验收；全类别扩展处于候选实现及运行验收中。要求以[统一日线规格](../specs/qmt-source-daily-history.md)的DSH/UDI条目为唯一正文，长期归属见[ADR0025](../architecture/adr/0025-unified-daily-data-owner.md)。

## 完整调用链

数据角色复用原公开事实输入库和原QMT批读/HPR协议，先读取缓存，按真实日历/上市资料和定日状态生成缺口计划。准备返回与实际覆盖分别记录，只有原批读回到的价格进入原Helper及DSB。原价和供应商前复权各有独立价格键、来源、参考与单位；旧日期、退出键和未知请求沿UDI-R13至R22处理。

同一不可变快照绑定价格目录、证券资料、定日股票池、官方日历及补充事实。数据owner通过排他租约和CURRENT的CAS发布；原WT Reader及文件ABI提供单只/最多64证券批量读取、实际首尾/条数和明确缺口。观衡新活动来源wt_breadth/wt_t2108只读取WT，沿原公式产生广度、RANA、MSI、T2108、广度推力、TRIN及换手活跃度。独立披露来源沿原模块运行。

## 运行与资源所有者

原SMP可显式组合数据生产线程与HTTP读取线程，父WT SourceMarketProcess的原Job管理整个进程。HTTP线程独占本代Reader/原生缓存，单次批量固定同一版本；数据线程独占来源客户端、输入回执和版本发布。SQLite沿原每次操作短连接，HTTP/SDK及原生资源在各自owner的finally关闭。单独命令仍提供显式单轮与持续入口。

定日事实缓存保留最多8日、原JSON合计16MiB，状态索引随对应LRU项移出及close释放。读取侧的原导入收据每根只准入/索引一次，后继证券读取复用固定索引，关闭释放索引和固定句柄。原股票路径每文件默认2000条；额外价格路径显式声明完整历史预算并分页读取，公开单次查询仍最多2000条。响应/原件/转换/历史总行数沿原配置额度；文件额度表示拒绝上界，实际读缓冲按已核长度创建，容量不作为RSS承诺。数据角色使用完整SHA判断CSV是否变化，原DSB逐件核摘要后复用；日期变化键才经原Reader检查旧日期集合。

原缓存、不可变成功DSB、定日事实、已发布generation、原请求slot、原件及失败输出分别保留。每个不可变准备阶段最多16个尝试，未提交旧尝试保留，新尝试由同任务声明；已提交内容变化明确失败。临时原生快照由原文件ABI租约在回调完成后释放，SDK/DLL硬阻塞由父Job按原D关闭。程序目录与这些数据根分离，安装、重装和回退分别核对。

## 资格与操作入口

来源单位未知、复权锚定日期/独立因子未知和PIT不足沿原元数据表达。停牌空量、上市前、资料未知与确认缺价分别分类，覆盖值保持真实。操作沿[安装与运行手册](../runbooks/unified-daily-data.md)，实际资格沿[验收记录](../evidence/2026-11-04-unified-daily-data.md)。原64证券1.094秒证据在输入及读取实现未变范围复用，更新任务的历史保留检查不加入公开批量查询路径。
