# 线上策略目标仓位历史

类型：功能规格。状态：accepted / deployed / verified。前缀：STH。范围：现有策略页的只读目标记录标签；复用现有标签、表格、展开详情及窄屏滚动样式，来源保持WT原生。

## STH1 事实与原生能力

复用WT-S原生CTA目标/输出能力：`ContextAccess.h::cta_set_targets`调用`stra_set_position(...,"gh_rt")`，`CtaStraBaseCtx::append_signal/log_signal`将每次设置追加到`signals.csv`。原生五列为code/target/sigprice/gentime/usertag；当前托管目标份数、原生行情时刻及参考价均可只读。该日志含重复设置，目标、实际持仓和成交各有来源。原生CSV没有权重、历史算法版本或逐笔业务原因，保持未知，历史证券不按当前八只集合删掉。

逐证券相邻同目标归并；A→B→A保留两次变化。各证券首次记录的原目标/差值为null，明确首次记录；零是实际零目标。目标份数使用非负整数，前后目标差值允许负数，不重算委托或资金。17位gentime按行情actiondate+HHMM+SSmmm解作上海时间，不用App接收时刻替代。

## STH2 来源及接口

GET `/v1/ui/strategy-target-history`必填strategy_id/version，limit默认20、1–100，cursor为最多512字符的不透明分页身份。拒绝额外/重复参数和请求正文，其他方法405。精确匹配CURRENT→同代Runtime→execution原ready/业务发布中的策略ID与版本，非当前选择返回not_current及空金融记录。未配置或原生文件尚未形成返回waiting，其他来源/身份错误503。

沿原业务引用同目录的execution.json读取原件，SHA须等于已核reference.config_sha256，固定所选策略存在，提取唯一output_directory。仅允许该目录下`outputs/<strategy_id>/signals.csv`；拒绝路径重解析、硬链接、非普通文件。Native配置、源路径、账户及usertag原文均不进入接口。读后复核Runtime引用及CURRENT，换代不拼接。

原生日志允许追加，单次固定句柄开始时的字节前缀，只投影完整行，末行未完成明确标记。复用SDK已存在的共享读/写/删除只读句柄，保留metadata自身的不可变读取语义。两次完整前缀SHA核同，拒绝截断、替换及可观察的前缀修改。顺序扫描保留逐证券前值和一页结果，单行有界，全部工作共享原App有界读池的2秒截止，不引入线程、数据库或新权威日志。

cursor绑定文件身份、前缀字节数/SHA及下一页原始行序。追加不改变已固定页面；旧前缀变动409并提示刷新。倒序分页的事件ID由源文件身份/原行序/原行SHA组成，不以时间或证券名去重。来源覆盖包含原始设置、变化、首次和同目标归并数量，三者合计等于完整原始行数。

## STH3 页面与验证

现有策略页增加“目标仓位记录”标签；时间、证券、原/新目标份数与变化直接可见，点击详情显示原行序/参考价和未记录字段说明。较早/较新记录按固定前缀翻页，刷新回到最新页；同查询失败保留成功数据/原时间，改选策略清除原页和详情。无来源、空日志和非当前选择分别展示。沿现有表格滚动样式适配390px，不新增设计体系。

验证覆盖真实WT原生文件→新消费者→原App读池HTTP→浏览器，核原生独立计数、分页不重不漏、同目标/A→B→A/首次未知、正常追加/末行半写/前缀修改/截断/替换、配置SHA与当前身份改变、只读方法/坏参数、异常保留和正常退出。源码预览、普通安装、生产采用分别登记；本功能无金融启停、真实下单或目标设置调用。
