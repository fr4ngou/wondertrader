## 配置与行为

| 要求 | 可观察结果 |
|---|---|
| WLC-R1 | writer.module缺省或WtDataStorage选择保留原DLL；显式WtDataStorageLifecycle选择适配DLL；非法模块启动前拒绝，模式固定于实例初始化 |
| WLC-R2 | 新工作在关闭准入后拒绝；已受理同步/异步/归档按受理序号完成存储阶段，回调及全部实际线程结束后才释放对象；重复release幂等，部分初始化失败由同一收尾回收 |
| WLC-R3 | 六张映射表由短注册表锁保护，pair身份到最终销毁前稳定；每块原SpinMutex覆盖取得/映射/读写/扩容/最后使用，过期判断和关闭在同一块锁内；tick cache有唯一原锁 |
| WLC-R4 | 生命周期/注册表/块/cache物理锁不嵌套，不在持物理锁时回调或join；归档dumper接拥有内存的快照，原格式/调用先后/清空规则保留 |
| WLC-R5 | checker保持原10秒扫描、600秒过期及归档worker启动后退出；关闭可唤醒；原生分钟算法、过期阈值、文件格式和清理范围保持 |
| WLC-R6 | 工厂按具体Writer类型析构，无公共IDataWriter虚接口/工厂签名变化；默认原DLL输入及身份不被适配覆盖 |
| WLC-R7 | 薄Session管理线程停止外部输入及接收线程，提交原生归档后close排空；Helper实际回读数据；marker或close返回只证明各自观察，不能代替数据持久成功 |
| WLC-R8 | 标准异常不逃出线程入口；任务结算或明确安全终止，失败不能写成成功排空；超时保留线程所有权，不提前释放活对象 |

## 回调与使用约束

metadata、casters、dumpers在首次工作前串行装配，寿命覆盖release；不支持运行期热注册。普通广播在存储序号推进、物理锁释放后执行，可查询，原同步写重入保持；归档dumper与准入查询仍占当前存储顺序，不得同步等待后续工作或关闭。release由回调及内部worker之外的生命周期owner执行。跨进程同时写相同存储根、严格I/O截止、崩溃事务性及新结构化持久完成receipt不在本规格范围。
