# 历史日线回测输入模型

类型：功能规格。状态：accepted。前缀HEM。依据模块C完整M1、NSK-R3/R6及[真实来源资格](../modules/qmt-source-qualification.md)的显式历史回放约束。

## 产品范围

本文归既有原生回测模块，只处理历史日线输入、回测假设与报告校验。沿三会话交付计划排除Grafana、新闻和研究服务/栏目；页面入口继续为原生回测、比较和报告。`evaluate_historical_model`是策略库函数，按本回测调用链消费，不新增面向用户的研究功能入口。策略介绍页仅名称、简介和版本，依策略目录规格。旧草稿标识作为历史证据保留；当前候选统一使用历史回测命名并重新核验。

## HEM-R1 事实和模型

固定真实来源批次、原始文件SHA、完整共同交易日历与源值；价格元/份、成交量从100份一手显式换算为份。源amount单位unknown、历史首次可知及修订unknown继续保留。回测模型显式声明amount按CNY解释、日末模型时钟Asia/Shanghai:15:00和本批实际received_at，dataset_sha256绑定history.source_revision。market_available_at保留None表示未知，禁止填写假定15:00或把本次实收冒充历史首次发布。

纯核新增独立evaluate_historical_model入口，与evaluate_history共用唯一规则实现和预算。严格入口保持原逐时点可知校验；回测库函数要求完整HistoricalEodModel，固定schema、假设枚举与规范SHA/带时区实收时间。实收不得早于所消费的日末模型区间；未知行可知时间仅在该显式回测库函数接纳。辅助数据原因果约束保持，缺辅助保留灰灯。模型结果qualified固定false，报告同时保存模型身份、原来源身份及明确中文回测限制，不能宣称严格无前视、真实实时或交易就绪。

## HEM-R2 原生消费

FrozenSessionInput新增可选historical_model，默认None沿原严格行为。runner显式解析同一领域值；原生现金ETF模型仅在完整回测假设声明下接amount_unit=unknown，model按CNY解释，原值不缩放。原HisDataReplayer/CtaMocker、loader、NSQ、成交及文件输出继续为唯一实现；原生输入和冻结历史逐字段相等。模型字段及假设参与输入/会话SHA，报告每个完整核结果带模型值，scope明确historical-eod-backtest-only。

保持旧严格核JSON/输入身份及报告字段；可选回测字段缺失时不改变严格输出。历史回测报告使用独立schema `nsb-historical-report-v1`，严格报告继续`nsb-report-v2`；两者共享原压缩/前缀重建实现，旧版本对新报告保持拒绝。报告验证器要求回测假设和schema相符，拒绝伪造qualified=true、移除模型或资格原因。来源/辅助限制、模型成交时点、费用及撮合模式分别报告。

当前B正式configured桥仍调用严格evaluate_history。该桥取得显式隔离历史回放profile和对应安装资格前，HEM输入仅交C原生回测；不得把历史回放候选作为B默认实时输入。B桥、执行权限及WT核心由原owner保持。本规格接入现有纯核与原生BT公开缝隙，不新增撮合、账户、订单或时钟引擎。

依赖升级须同时核普通安装及实际导入。纯策略包的运行身份由包内source_manifest和安装METADATA共同准入，依赖集合/精确版本/包版本须一致，并核实际依赖版本；输出身份沿同一声明。signals使用已绑定core wheel SHA。清理源码内重复的包版本、core身份及依赖常量，数学规则保持原实现。来源声明读取只在包导入阶段执行、有界且拒绝失配；计算调用继续消费已冻结领域值。

依赖声明和实际发行身份分别核验。对项目支持的规范版本，公开`==版本`可接纳同公开版本的合法local修订，显式local按完整版本匹配；源码选择和运行时共用身份入口保持同一语义。包自身声明与METADATA完整版本、依赖声明文本继续一致，实际所选wheel及完整版本由组合锁和摘要固定。此匹配不授未锁定发行或不同公开版本资格，数学及报告字段保持。

## HEM-R3 主链与验证

先以真实交付127的401日、9证券共同区间生产configured1.2.0的八角色历史及九证券原生读取集合，执行原生回测并保存完整报告和原生funds/trades/positions；预热/目标/交易结果按实际事实记录，不预设非零交易数量。纯核最后前缀与原生末记录逐字段一致，输入SHA、批次SHA、假设及实收可回读。

现有原生回测页通过原工作区/归档HTTP读取新报告判别字段与当日投影。客户端要求模型、批次、未知真实可知时间和qualified=false相符；无显式回测判别的模型摘要拒绝。详情用短说明呈现实际批次接收时间（固定上海时区）、15:00日末假设和源金额单位未知/按元解释，完整摘要与SHA折叠查看。策略介绍页继续只展示名称、简介和版本。验收使用普通安装App、生产SPA和桌面/手机浏览器实际启动、记录读取、归档恢复及读取故障恢复。

再覆盖严格模式缺可知/晚到拒绝、模型缺失/篡改/未来实收/非法单位、辅助未来拒绝、重复前缀/序列化/身份变更和报告资格篡改。全部辅助进程沿原native.run、隐藏Job、单一期限/有限输出和真实闭合。开发主链、普通安装、B隔离实时/委托/撤单、HTTP/页面、完整M1和生产分别登记，后继独立双轴审查关联最终源SHA。
