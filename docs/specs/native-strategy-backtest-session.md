# 策略同核与原生回测会话

类型：功能最终规格。状态：accepted。前缀：NSB。细化[NSK](native-strategy-kernel.md)与[NSQ](native-strategy-quantity.md)的原生组合；当前实现先贯通隔离回测，实时CTA、其他策略族和全部观衡业务保持原目标范围。

## NSB-R1 原生接缝与范围

复用WT-S01、WT-B01/B02的固定原WtBtPorter公开C ABI、CtaMocker、日线final loader、理论仓位、撮合、费用及输出。业务会话只组合已迁入configured核与NSQ；薄Porter负责ABI、线程、回调及完整向量读回。保留现有独立包，不复制算法、数量阶段、撮合或账户账本。每个原生进程只承载一个会话，首次从明确空理论持仓开始，不接Trader、Parser、Executer或柜台。

signal读取集合与execution提交集合分别从同一稳定配置导出，读取并集最多16，execution最多8；signal专用证券不进入数量或提交向量。全部标识经显式沪深代码映射，禁止按名称猜角色。589680.SH信号、589000.SH执行的九证券读取、八证券提交必须实际验证。

## NSB-R2 冻结输入与因果读取

在原生启动前准入完整不可变配置、日线及辅助事实、source/factor身份、执行原价和明确理论资本。callback不联网、不下载、不读临时外部文件。原生loader消费预先准入的日线Bar值，on_init登记需求，on_bar只复制，on_calculate才取完整闭合前缀。

每次根据原生日期/时间核截止，逐证券比对原生实际返回日期和OHLC/volume/amount与冻结来源；元数据按同证券同日期附回，不能以已知未来辅助补历史。各信号证券日期集合必须一致、完整且未越截止。日线闭合时钟、复权/单位由输入manifest明确；执行原价单独校验。预热不足呈明确状态并保持空提交，不能以短前缀重新种EMA。

每次调用原单一evaluate_history，完整结果及配置/输入/因果身份保留；同一前缀与独立纯核逐日完整结果一致。辅助缺失沿原核分支与资格理由展示，禁止宿主另造灯或入场规则。来源修订、配置或factor变化须重新建立会话，不能在已有理论状态上无条件套新输入。

报告采用显式版本的共享历史表示：完整增长的daily_frames与allocation_events各保留一份，每日保存重建所需的完整当日字段、身份及引用边界。提供唯一的公开前缀重建接口，逐日重建整个EvaluationResult须与独立纯核相同，包括预热、缺辅助和零配置状态；禁止每日再次保存整个累计历史。保留空间随历史和每日固定规模快照线性增长。完整输入范围、单条和会话累计预算均明确计量，在setter之前完成本轮空间准入；不能通过抬高硬预算、缩短正常多年范围或丢失完整前缀语义解决表示问题。默认窗口100、1250日、9读取/8执行的原生回测及准入上界必须验证，完整输出继续受NSH有限预算约束。

公开重建入口自行保证同版报告校验与容量约束；原始dict不能绕过共享行数、单行容量和完整header/身份字段检查。重复读取可先通过唯一校验器形成已验证、深度不可变的报告值，再按索引重建；不得仅凭类型标签、调用者承诺或可变对象身份跳过准入。调用后修改原始输入或返回结果均不能改变已验证报告。完整扫描避免每个前缀重复准入整份报告，同时保持显式check贯穿耗时验证和展开。

## NSB-R3 原生事实采集

薄层原值与数量模型事实分层。仅固定、初始flat、单上下文、现金ETF多头、只用本会话绝对目标setter的CtaMocker模型可以采用经源码与实际输出验证的采集规则；不能将该规则推广到实时引擎、柜台、条件单或外部恢复目录。

同一calculate的owner线程连续读取完整枚举、各execution total/valid、first/last entry、raw价格和fund0..3，期间不提交目标；前后枚举相同才形成coherent capture。当前明细entry为0时actual为0；entry存在时actual取原total。枚举与actual不同时明确pending绝对目标；相同时只有在本限定模型的源码和实验支持下认定无待处理差量。flat、首次pending、部分进展、平仓再入场、T+1、冲突pending均须对照原生trades/positions实际输出，不以字段名自行授资格。异常、未知、负量、非整数、缺证券或额外持仓阻止提交。

capture身份绑定会话、原生时钟、真实采集序号和完整raw内容；不用本机时间或每日input摘要冒充新观察。明确初始资本加原fund0形成理论NAV；现金按同一capture的NAV减完整实际持仓raw市值派生。费用预留及来源显式提供，未知则沿NSQ等待；禁止把flag0当NAV、把NAV当现金、把pending当actual或重复乘100。不新增持续现金账本或数据库。

有界精确资金派生及其十进制表示独立于调用线程的Decimal上下文，包含prec、Emax/Emin、traps和rounding；转换保持合法输入精确性，非法或超界输入返回本层明确错误。不得修改调用者全局上下文。默认及受限指数/异常陷阱下，同一实际原生capture产生相同有限NAV/cash；除纯函数验证外须覆盖真实回调。

## NSB-R4 数量推进与提交

核心完整execution权重、统一原allocation日期和稳定配置形成EconomicTarget。先用同次capture推进既有阶段，确认旧目标实际收敛后才切新代际；未解决pending或supersession_required保持明确阻断，不能假装已取消。初始化全零无提交；dated-zero沿原阶段处理。

数量完全调用NSQ.advance。需要提交时一次完整构造execution目标并交薄Porter全向量预校验和回读；同轮不追加逐证券补救。提交失败锁存incomplete，保留原生原件并隔离输出。capture与纯阶段不是原生提交/成交确认；下一次原生观察才推进。会话只持计算/阶段值和有限结果，不创建持仓/订单/成交owner。

## NSB-R5 进程、输出与验收

Session在公开入口完整读取并重建结果预算，复验既定整数硬上限；缺字段、非有限值、错误类型或越界值按会话准入错误拒绝。运行期间只持本次独占预算值，调用方修改原对象不能改变已准入的条数与字节限制。

进程准入、Job预绑定、单一绝对截止、有限输出/管道及父死亡回收沿NSK-R5。薄Porter和业务会话的同步函数不自行承诺中断native；外层受管owner必须实际验证。所有异常在C ABI边界锁存，callback禁止stop/release/join，run返回后owner释放日志；原生库保持进程期装载。

先验证原核逐日完整结果、signal/execution替换、初始化/新代际/重复、原生actual/pending及阶段、完整向量、现金/费用/T+1和输出一致，再验证包装后的独立安装产品、搬迁、HTTP和页面。人工可核合成闭合日线与真实QMT来源分别取证；合成同核回测不授真实来源、实盘、实时CTA或完整业务完成。未知结果、父超期、提交中断或缺输入均不能生成完整成功报告。
