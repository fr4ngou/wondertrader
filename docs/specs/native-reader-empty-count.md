# 原生随机 Reader 空历史计数

类型：最终功能规格。状态：accepted；前缀NRC。用户于2026-10-21批准[最小提案](../migration/native-reader-empty-count-proposal.md)，并要求代码注释。范围为一个原生函数的空历史数量输出及必要回归。

## NRC-R1 正确数量

`WtRdmDtReader::indexBarFromCacheByCount` 在历史数组为空时，将引用输出count置0，再返回NULL。上层`readKlineSliceByCount`据此只计算实际存在的历史和实时数量。无任何数据时返回空；只有实时记录时返回实际实时条数；正常非空历史及混合尾部行为保持。

所有有效切片的声明数量须等于各数据块累计数量；读取者不能按声明数量访问不存在的数据块。空历史和真实无成交/停牌/未下载的来源含义分别判断，本修正只处理底层数量输出。

## NRC-R2 范围与注释

仅修改`src/WtDataStorage/WtRdmDtReader.cpp`上述空数组分支，新增count=0和必要括号。中文注释解释count是历史输出数量、上层依据它构造切片，因此空历史必须归零；不添加单次开发历史。

函数签名、非空算法、类布局、文件格式、线程、锁和交易路径保持。其余冻结核心差异保持。若发现其他问题，单独记录、复现并提交必要范围。

## NRC-R3 根因回归

使用公开create/delete工厂和原Helper。隔离静态fixture覆盖无历史/不足请求/等于请求/超过请求、无实时/部分实时、历史截止与当天截止，独立按输入时间筛选和尾部oracle核对条数、数据块及字段。重点覆盖无历史+无实时以及无历史+部分实时；原样DLL产生失败，修正后通过。

已有正常历史/范围/日期与真实428根回读资格，按实际输入复用或对受影响Reader补验；对本修正不得声称增加了实时并发、完整停止或生产交易资格。测试内DMB静态构造不是原Writer盘中并发测试。
