# 策略注资、提取与收益率方案

类型：实施规格。范围：原单策略资金进出登记、对账及起算后的投资收益率。

## 目标与现状

用户需要在给策略追加资金或从策略提取资金时留下一条可对账的记录，并让观衡显示剔除资金进出影响的投资收益率。策略净值沿 WT 原发布，包含现金与持仓市值。逐笔成交用于对账，收益率计算消费合格净值和策略资金进出事件。

原共振模拟策略已有 2026-11-04 17:13:01（北京时间）的起算基准、同账现金原点和当前净值。从该基准至 2026-11-12 19:00 期间的零追加、零提取已经用户确认并登记。正式历史证据保留在受控运行环境，仓库仅登记日期、确认范围与实施规则。起算前历史沿原证据范围展示。

原 WT 已提供资金、损益及账户观察能力，详见[WT-S08](../development/wondertrader-capabilities.md)与[策略资金只读消费](strategy-capital-observation.md)。当前单策略路径用账户现金差额推算策略现金，账户快照没有逐笔策略资金进出字段。沿用原 WT 财务所有者及策略经济身份，新增最小的资金事件持久记录和收益率投影。观衡通过原策略读取接口消费结果。

## SCF-1 记录策略资金事件

1. 首期登记入口同时支持追加和提取。追加在资金已归入所选策略时登记为流入，提取在资金已划出所选策略时登记为流出。系统绑定原凭据并记录生效时间。已有明确到账或划出回执时，可复用原回执自动登记。
2. 资金实际归属发生变化的账户内划拨，沿已有策略资金归属流程取得证明，使用同一事件格式。
3. 同一原回执或操作请求重复提交，返回同一条记录。持久化结果未知时按原 ID 核查。错误记录通过引用原 ID 追加更正，计算按更正后的有效记录重算，原记录保留。记录随原策略经济身份跨 WT 正常重启接续。

| 字段 | 含义 |
|---|---|
| `flow_id`、`source_ref` | 稳定事件 ID 及到账、提取或划拨凭据的受控引用。支持重试去重和原件核查。 |
| 策略 ID、资金基准 ID、账户绑定摘要 | 定位实际接受或划出资金的策略经济身份。跨运行代沿原基准接续。 |
| `direction`、`amount_cny` | 流入或流出。金额为正数，人民币十进制字符串，按实收或实划金额登记。 |
| `effective_at`、`recorded_at` | 资金实际计入或离开策略的时刻、系统登记时刻，使用带时区时间。展示为北京时间。 |
| `nav_before_cny`、净值时点及来源引用 | 资金变动前的合格策略净值与证据。缺失时先保存资金事件，分段收益待该净值补证。 |
| `nav_cash_receipt_ref` | 资金变动已计入原策略净值所用现金的对账证据。缺少时保留流水，收益待对账。仅修改配置或内部归属尚未进入净值时填空。 |
| 更正引用 | 追加更正时引用原记录并保存原因。原登记与审计历史继续可追踪。 |

## SCF-2 计算和展示

- **期间无资金进出。** 收益率为 `期末净值 ÷ 期初净值 − 1`，起点使用现有已核基准。已知范围只有零流入时，待核清同一期间的流出记录后发布收益率。日志刚启用时，空事件列表本身只说明尚无登记，历史覆盖沿对应证据。
- **期间有资金进出。** 每次资金变动前结束一段。`资金变动后基准净值 = 变动前净值 + 带符号的资金流`，再从该基准开始下一段。累计收益率为各段 `期末净值 ÷ 期初净值` 相乘后减一。WT 使用原十进制金额计算，观衡展示百分比、起算时间、估值截止和资金事件覆盖。期初或分段基准非正、资金流未对账或关键净值缺失时，公开原因及可核算范围。
- **同一金额只进入净值一次。** 账户资金进出已通过现有券商现金差额进入策略净值时，资金事件只用于调整收益率计算。账户内分配沿现有归属逻辑形成实际策略现金，收益率消费同一份已登记事件。交易买卖、费用及估值变动继续通过净值反映。
- **使用同口径的净值。** 每个变动时点使用前一资金变动之后取得、且与本次变动之间没有未计损益的净值证据。相同时点的多笔资金变动需使用同一份变动前净值，再合并调整。流入、流出覆盖分别核对至期末持仓估值和实际现金快照中较晚的时间，两时点间有资金变动时等待下一份能共同反映该变动的估值。策略资金和收益投影由现有账户观察线程刷新。
- **保留收益截止。** 同一运行代等待新估值对账时，继续展示最近可复算的已核收益、它的期末净值和时点。补登或更正会重新核实原收益期间。WT 重启后，从恢复后的实际估值重新选择对账终点，原流水和覆盖继续沿同一资金基准读取。
- **分账后的接续。** 已有策略继续使用原本金、账户绑定与资金流水范围。分账后的新估值来自 ASA 归属的策略现金和同批自有份额的原价市值。未确认费用或缺持仓报价时保留估值资格的缺失原因，参考净值不进入投资收益。资金观察线程消费已发布的只读估值，沿同一资金流水计算和原子发布。观衡核同该策略的原本金、估值时点与自有净值后展示结果。 最近已核估值依据按原策略资金范围保存在同一 SQLite 的独立投影表。重启或报价缺失时，仍用有效流水重算该点并保留原时间。未对账的现金或行情不得更新该点。观衡沿原资金原点只读接续历史净值及其估值时间。分账后的持仓、现金和成交从独立归属账本读取，分账前的账户级明细仍保存在原历史范围。

示例为虚构金额。期初 100 万元，注资前净值 110 万元，注资 50 万元后净值为 160 万元，最后净值为 176 万元。两段收益均为 10%，累计投资收益率为 21%。

提取示例也使用虚构金额。期初 100 万元，提取前净值 110 万元，提取 20 万元后净值为 90 万元，最后净值为 99 万元。两段收益仍为 10%，累计投资收益率为 21%。若一次提取使净值归零，已完成区间结算到提取前，后续由新的正净值启动下一计算段。

## SCF-3 实施与验收

1. 固定原模拟策略和 11 月 4 日基准，保存用户已确认的零流入时段，核对同段资金划出及估值截止。若两方向均有证据，从原基准至合格净值先发布无流量区间的收益率。
2. 在现有 WT 财务持久化路径实现资金记录、回执防重、追加更正和跨代读取。分别用隔离模拟数据走通已生效追加及提取 → WT 资金投影 → 观衡原策略页。旧版本仍可读原有净值与资金字段，新收益投影可选读取。
3. 验收零流量、有注资、划出、同回执重试、写入中断后恢复、追加更正、缺注资前净值和未知历史覆盖。专项验证净值已含到账金额时，登记前后净值一致，收益率仅反映投资变动。观衡核对收益率、原始时点与待补原因，切换策略后只展示该策略的流水和结果。

## 受控运维登记

从已发布 WT 运行包的 Python 环境执行下列命令。参数分别指向实际执行配置、配置的 SHA-256、原策略 ID 和单条待登记 JSON。命令核对策略输入和账户绑定摘要。原始登记保存在该配置的 `output_directory/strategy-capital-flows.sqlite3`，需随同一策略基准和账户绑定保留。输出的 ID 和登记时点用于重复提交核查。

```powershell
python -I -B -m guanheng_wt_runtime.strategy_capital_flow --execution-config $configPath --config-sha256 $configSha256 --strategy-id $strategyId --record $recordPath
```

下例使用虚构时间、金额和凭据。追加和提取各登记一条 `flow`，以 `direction` 区分。只有在到账或划出已核对、且已计入策略净值所用的现金来源时，填写 `nav_cash_receipt_ref`。一笔资金流水已发生但待对账时填 `null`。缺变动前估值时，三个 `nav_before_cny`、`nav_observed_at`、`nav_source_ref` 字段同时填 `null`。

```json
{
  "kind": "flow",
  "id": "demo-withdrawal",
  "source_ref": "demo-transfer-receipt",
  "direction": "outflow",
  "amount_cny": "200000",
  "effective_at": "2025-01-03T10:00:00+08:00",
  "nav_before_cny": "1100000",
  "nav_observed_at": "2025-01-03T10:00:00+08:00",
  "nav_source_ref": "demo-pre-flow-nav",
  "nav_cash_receipt_ref": "demo-reconciled-cash"
}
```

核对完从原起算基准到所选时间的流水后，按方向登记 `coverage`，包括 `id`、`source_ref`、`direction` 和 `through`。两方向各有自己的对账凭据。补登或更正早于已核截止的事件后，重新核对受影响方向的覆盖。更正使用 `correction`，包括 `id`、`source_ref`、`original_id`、`reason` 和 `replacement`。替换对象填写完整流水字段，剔除 `kind`、`id` 和 `source_ref`；作废时 `replacement` 填 `null`。

原共振模拟策略的首次登记和已核收益见[发布后验真](../releases/2026-11-12-wt-strategy-return.md#首笔实际收益验收)。
