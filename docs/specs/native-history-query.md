# 原生历史查询接入

类型：功能规格。状态：accepted。依据：用户确认以WonderTrader为底座、重合能力全部复用原生实现，以及[原生行情方案](../migration/native-market-integration-plan.md)。此规格限定历史m1查询的开发切片，整体分钟订阅、交易与业务适配继续独立验收。

## 目标与职责

现有服务的 `history.query/read` 和 `NativeHistoryLoader` 通过同一 Store 读取已发布DSB。配置原生Reader后，由公开 `IRdmDtReader` 承担历史索引与查询，退出该路径的Helper完整解码及全量筛选。Store继续拥有sidecar来源、摘要、冻结标记、覆盖证据及单写者发布。Helper保留原生写入、发布验证、合并和恢复用途。

复用能力WT-D01/D02及公开Reader工厂，依据[数据能力说明](../modules/wondertrader-data-capabilities.md)。无需新增数据库、HTTP服务或核心修改。现有未配置的开发候选保持兼容；最终默认接线以本切片和业务入口验收为前置，原生路径失败返回明确错误，禁止静默退回旧查询。

## 接口与输入

受管启动配置增加可选 `native_reader`：`library` 为绝对DLL路径；`sessions/commodities/contracts/holidays` 为真实WT基础资料的绝对UTF-8 `.json`路径；`cache_bytes` 为全部在用和待释放Reader已加载历史的解压字节总预算（1根bar至1GiB）。配置均显式必填，在创建时校验；不提供测试日历或合成证券作为默认值。JSON先检查非空根对象、四类实际访问结构、重复键、NUL及深度，再交原配置加载器，避免畸形根类型进入其断言。未知扩展字段保留，配置内容在适配实例创建时固定，换代期间变动需重建适配实例。外部查询不能修改启动配置。存储根沿既有 `history_root`，仅限受管历史根，禁止原Writer在同根写入DMB。

请求和响应沿用 `guanheng.market.v1` 的m1闭区间、右端时间、元/股/元、未复权及现有覆盖语义。无预期日历依据保持Unknown，空数据不证明完整。count/派生周期在后继同一查询接缝补充，不在此次声明支持。

后继窗口/周期能力由[NQW规格](native-history-window.md)在同一history.query接缝扩展；本规格的普通m1覆盖请求及旧响应形状保持。

DSB原生调用前核sidecar、完整内容摘要、冻结标记、CMP_V2头/type/长度和ZSTD帧声明大小；后者必须为正、为bar大小整数倍且在条数/缓存预算内。完整解码只由原生Reader执行。固定上游count在截止早于首条时回退begin，因此适配层先以固定一条输出和128MiB窗口上限的ZSTD流检查首条合法且不晚于2030-12-31 23:59，防止进入该边界；不再次全量解压。每内容代际首次用原count读取全部声明条数，核实际块、排序、字段及时间，再保留行数和首末边界；不保存第二份历史数组。首次全量匹配失败明确报错，不默默截断未来数据。

## 生命周期与并发

所有查询在Store互斥锁及RootLease内串行执行。借用切片在复制结果后释放，Reader和基础资料由适配对象拥有，公开delete工厂先结束Reader，随后释放基础资料及DLL。

内容代际变化时创建新Reader，旧Reader在唯一后台释放线程执行原delete/join；禁止并发clearCache。最多一个待释放实例，释放尚未结束时再次换代返回Backpressure；预算同时计入待释放历史，禁止无界保留。预算无法容纳双实例时，先退休旧实例并返回Backpressure，释放完成后重试创建新实例，避免更新永远无法推进。旧实例只销毁，不再查询或访问文件。新实例与旧实例分别持有sink/基础资料，跨线程不共享可变Reader状态。所有对外返回bar为自有副本。

关闭先结束查询，再销毁在用Reader并等待释放线程；原后台5秒检查周期使关闭可能等待约5秒，属于关闭时间，不能计为页面请求延迟。操作系统调度不提供硬实时截止。文件校验/原生调用仍为同步有界大小操作；history.read在本地读取完成后检查剩余预算，history.query只有条数/字节限制，其单次磁盘/原生调用没有可中断执行截止；客户端HTTP截止也不代表服务端取消。禁止将本查询接入策略ticker回调。

原生range有首条前及内部空档边界：先按已验证首末判断交集，空交集直接返回空；对原生候选仅裁剪越出请求区间的条目，并检查有序与条数，不在适配层重新索引全量历史。原析构停止标志为普通bool；复用公开delete/join只取得限定运行证据，不宣称已证明整个框架无数据竞争，DMB混读/热卸载继续保持未验资格。
