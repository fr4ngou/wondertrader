类型：缺陷修复规格。范围：原版当前日纯计算的说明文本；算法固定为351f9d5，原参考目录及既有策略保持原身份。

## OCF-1 触发和职责

固定原库`base.analysis.strategy.sh50.run_sh50_strategy`的P3分支允许`shares_delta_yi=None`，其`money_ok`为真。生成原因的`{sd:.1f}`随即抛出TypeError，整份九证券当前信号失败。份额缺失是合法事实，填零会改变经济语义。

当前计算接缝负责对原函数的`reason`赋值中的数字格式化表达式提供可空文本渲染：None显示“未知”，已知值沿原`format(value,spec)`。仅在当前计算子进程装配此渲染；原库文件先按原清单SHA核验并保持原字节。转换前后将全部`reason`赋值值体置空后的AST必须完全相同；分支、指标、阈值、价格、交易日期和资金逻辑保持原结构。转换仅用于已核SH50函数，其余函数保持原函数。
