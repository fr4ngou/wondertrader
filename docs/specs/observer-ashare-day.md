# 沪深北日终广度与换手

当前阶段为独立观衡后续版本的隔离候选。已交付 a74 保持固定，WT 交易验收独立进行。

## 目标与职责

四项观察为 `breadth.ashare`、`trin.ashare`、`rana.ashare`、`turnover.gt5.ashare`，均为 `/1` 方法版本。
股票日终计算由 `market_breadth.stock_day` 唯一持有；显式 scope 约束证券范围。
已有 `.shsz` 历史单独保存。停牌空量且空换手可确认未超过5%的修正使用 `.shsz/2`，完整历史重算后才接纳升级。

## 原件合同

`ashare_snapshot` 接收绝对路径与SHA256固定的 `guanheng.ashare-public-inputs.v1`。
清单字段为 schema、date、closed_at、universe、shsz_daily、bse_quotes、bse_static。
universe 是有日期的普通A股股票池（members、market_count、exchange_counts），包含沪深北三所。
其所有者负责普通股类别与上市资格，原件引用保留来源链；本适配器核日期、数量、唯一身份与各来源完整覆盖。
沪深为 BaoStock 原始日线；北交所为公开行情分页和证券表分页。每件原件包含相对路径、SHA256和实际 received_at；股票池只包含路径和SHA。
路径限定在清单目录；重复键、非有限值、超预算、缺页、重复证券、异日或尚未闭市原件使整批失败并保留旧快照。

北交所 hqcjsl 为成交股数，xxfxsgb 为流通股数，xxzgb 为总股数。
换手率为100×hqcjsl/xxfxsgb；严格大于5的资格同时用整数交叉相乘核对。
价格使用 hqzjcj、hqzrsp；仅接纳已核正常状态 xxtpbz=F、xxzrzt=N 和人民币、数量单位1。
未知状态保留待核原因。此阶段没有冒算北交所停牌、首日、询价等状态。
北交所行情必须是15:30以后同日结果。原接收时间保留，历史首次可得时间仍为空。

## 发布与运行

原独立采集 owner 的预算、lease、对象库、原子发布及每天北京时间09:00调度继续适用。
配置显式固定输入包SHA，更新包需要采集部署更新配置身份。本版本的输入消费能力与持续在线采集能力分别登记；固定包不能声称每天自动取得新行情。
App只读已发布目录。HTTP、CSV和页面读取相同分区、定义和覆盖字段。
默认用户配置不包含SDK账户快照。外部来源缺失时如实显示缺失与更新时间。
