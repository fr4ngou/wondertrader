# 全市场分钟采集、覆盖与自动恢复

类型：功能规格。状态：accepted。前缀MCC。需求来自Root本轮分钟模块分工；范围为既有QST接入、原生采集与历史补缺的自有适配。日线owner、账户交易、观衡UI及Root CURRENT分别由原模块维护。

## 目标与原生接缝

沿WT-D01/D02/D03/D05/D06/D11复用原ParserAdapter、DataKit、同步Writer、StateMonitor、标准Reader及已有来源补齐。Writer独占原存储根，负责分钟构造和自然收盘归档；Reader拥有形成中数据的读取，不直接解析、复制或映射活动DMB。既有SourcePreparingMarket、RetainedReadClient及Importer拥有补缺请求身份、来源原件、原生导入及恢复。自有采集owner负责将这些现有能力连成可观察的运行流程。

当前实际缺口为逐证券时点和覆盖不足、固定订阅与动态已知名册缺少对照、历史补齐依赖查询触发而缺少采集owner接续。框架原有归档与重连继续使用，新增实现只负责覆盖投影和有界接线，不新增行情数据库、常驻服务、系统定时任务或分钟算法。

## 所有者与恢复

QMT订阅和资料调用仍归原策略线程，接收线程将已校验批次同步交原Writer。覆盖投影只在成功交付后登记纯时间与计数；原消费失败保持其已知/未知结果。管理线程复用现有采集循环推进维护，不在接收回调内执行磁盘扫描、来源请求或历史导入。

盘中读取沿[受管分钟Reader](native-minute-reader.md)，归档读取及独立补缺来源沿[CNH](collected-native-history.md)。补缺使用同一已声明来源语义，原值不同沿既有冲突返回，保留来源和原文件，不以人工乘数或覆盖解决。来源只有历史日能力时，当前日缺口保持待闭合/待来源支持，并由原owner在可用范围内后继推进。

动态名册的完整资格取决于真实Source分组和完整分页，既有6982或固定50指数分别只证明该原集合。沪深北或特定类别的接入缺口按源能力、代码映射、订阅和实际分钟分层列出。

## 交付与切换

所有新增工作树、候选、临时文件与证据使用E盘。旧原件和历史继续保留。候选固定生产源码及依赖身份，复用已交付标准Reader和原生组件；新增WT框架行为须沿原批准规则，当前方案不包含框架修改。

正式采集切换前交Root完整原/新配置、实际进程身份、影响的历史/报价监听、原请求交接点、关闭截止、成功条件及回退动作。隔离验证和候选提交自主推进；正式部署、自然收盘、断线恢复和长期运行资格分别登记。
