# 观衡人工验收修复与视觉重设计

类型：功能规格。日期：2026-11-01。功能要求状态：accepted；整体视觉实现状态：proposed，用户选择效果图后实施。适用范围：独立观衡及其WT只读数据接入。

## 目标与事实边界

修复用户八张验收截图中的搜索、行情接线、数据覆盖、图表、策略详情和回测入口问题。观衡保持只读并独立部署，WT继续拥有通信、行情、策略和执行。只保留正式共振市场状态ETF策略最新版1.1.2；历史交易记录无需迁移，已确认现有全部持仓归属该策略。

当前18120观衡接入新WT账户只读实例；原WT行情/历史/采集实例继续运行。前次启动缺少行情连接及回测归档环境配置，不能将缺少组件发布表述为对应服务故障。当前账户配置标为live，新增工作不得发送委托、撤单或启用执行器。长期服务和QMT三条运行策略保持，QMT界面操作统一由集成者协调。

## 验收要求

| 编号 | 要求 | 验收标准 |
|---|---|---|
| OAR-01 | 证券搜索和个人观察 | 支持中文简称、拼音首字母/全拼、代码及代码前缀；68817返回真实匹配候选，不补零猜测证券；选择候选后使用规范代码/交易所。搜索、加入、刷新和行情读取完成一个真实链路；歧义明确列候选。证券目录来自已有WT/QMT真实资料，覆盖已支持的股票、ETF和指数 |
| OAR-02 | 上证基准连续性 | 对每个缺线图核对实际数据、日期和连接；有数据的日期完整显示，指标与基准按交易日对齐，保留各自真实缺口；不得连线、插值或造点冒充补齐 |
| OAR-03 | 中文金额 | 卡片、纵轴、tooltip和表格使用一致的元/万/千万/亿自适应格式，保留正负、精度及单位；可查看完整原值，导出保留原数值语义。回归截图的负885123435.815等量级 |
| OAR-04 | 四组观察的历史与基准 | 市场广度、换手活跃度、盈利与回报、高管增减持分别核查真实历史覆盖，优先补齐已有来源；每组顶部增加上证指数，共享日期范围和光标。切换30天/半年/一年/全部返回相应真实记录；无法补齐的日期记录来源原因与可获取起止，扩大横轴不算补齐 |
| OAR-05 | 完整市场广度 | 按用户图5提供上证指数、RANA及MSI、T2108、Breadth Thrust与涨跌家数差、TRIN；可分组而保持日期联动。所有指标给出公式、样本范围、预热、单位、阈值和覆盖；沿已有口径核对，MSI累计起点明确；指标在其他下拉项存在不构成本页完成 |
| OAR-06 | 回测报告可读 | 修复已存在WT正式归档→观衡列表→报告详情读取。未配置、真实空目录、错误路径/格式、已停止来源分别给出准确中文状态；现有正式报告不得因漏接配置被显示成读取失败；实验或SDK演示不得冒充真实回测 |
| OAR-07 | 唯一策略的实际详情 | 保持唯一1.1.2，展示持仓数量/可卖/市值、账户总资产/现金/可用资金，以及可取得的策略预算、运行状态/开始时间/时长和收益率。账户现金与策略资金归属分别标识；使用WT原有发布和已确认持仓归属，不新增资金账本。未启动执行器准确显示未启动；累计收益缺少本金/现金流基准时写明原因，不伪造收益或恢复旧成交 |
| OAR-08 | 完整只读运行状态 | 接入实际运行的WT账户及行情/历史/采集事实；多个实例按真实身份区分，不能以账户实例未声明采集推断全系统未启用。已配置服务核实真实能力、最后成功、数据时间、异常原因；真正缺少配置使用明确处理说明，不泛化为未知。观衡不启动或控制WT组件 |
| OAR-09 | UI重设计 | 先调研官方开源组件库，保留可复用React/ECharts能力。提供三张独立设计效果图供用户选择，再实施全局视觉。采用可读中文字号、紧凑层级、统一输入/按钮/数字/图表，减少大标题、巨大空白、重复只读/权限解释和多层阴影。桌面为主并兼容窄屏，异常和空状态有实际原因 |

## 实施及验证顺序

先完成对应模块真实主链及当前部署接线，再集中覆盖根因回归、异常和审查；输入未变的有效证据复用。数据缺口调查、库调研和调试输出各留模块工作记录。新增WT框架修改继续遵守原审批边界，不开展上游线程问题研究。

完成要求为已安装入口的实际搜索/行情、完整图表和策略/回测可读。验证绑定源码、版本、配置与数据根，报告逐项说明已完成、未完成、待来源条件及剩余风险。视觉改造等待用户选择期间，后台接入、数据补齐和现有页面的功能修复继续。
