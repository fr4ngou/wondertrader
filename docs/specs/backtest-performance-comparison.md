# 原生回测绩效与比较

类型：功能规格。状态：accepted。前缀：BPC。范围：COP-R4，沿[NBW已完成归档](native-backtest-workspace.md#nbw-r6-已完成回测只读归档)提供派生展示，原生金融事实继续归WT。

## BPC-R1 来源与身份

只消费同一显式work_root内带完成receipt的归档。复用BacktestArchive的原request/installation/result/native outputs摘要核验及报告族唯一validator，不引数据库、复制资金账本或重跑回测。请求固定run_id及receipt_sha256，配置、报告、session输入、安装、策略/模型身份完整返回；原件变化、未完成或身份失配明确拒绝。configuration.session_sha256保留原会话文件摘要，顶层session_sha256保留规范化请求会话摘要，两者分别核实。单份报告与比较共用既有backtest_reader及一次绝对读取截止，串行读取第二份不重置预算。

## BPC-R2 指标与数据边界

读取使用独立单线程和四个等待位，覆盖报告切换时尚未结束的旧读取与新绩效/记录请求。排队、原件校验和双报告比较共用30秒总截止，浏览器保留31秒含传输余量；切换报告取消旧浏览器请求，服务端仍按原截止收尾，不延长原已执行工作的期限。该读取配置不影响WT、策略、金融命令或其它行情/账户读取线程。

初始本金取本次已准入session.policy.initial_capital_cny，原生报告capture.basis.nav_cny表示该本金加WT净损益；capture.funds的net/realized/dynamic/fees保留原生累计语义。每条记录经唯一公开project_session_record读取；null capture保留未知点，不补零或前值。

收益率=(末个合格日末模型净值/初始本金−1)×100；回撤从显式初始本金和已观察日末净值的历史峰值计算，展示名称为“已观察日末最大回撤”，不推导盘中风险；原生累计费用取末个合格capture.funds.fees，不累加每日累计值。计算沿有限精确有理值，最终有限数值/十进制字符串投影；派生不可表示时明确不可用，不返回NaN/Infinity或伪造零。

报告零记录或没有资金观察时保留内部身份和明确空指标；唯一1.1.2报告预热日已有资金capture时仍可展示日末净值，策略信号继续标预热。部分capture缺失保留总记录数、观察数、缺失数与末合格交易日，界面说明指标仅覆盖合格观察。最多4096个日期/净值点，响应沿512KiB上限，单份与比较均不截断冒充完整。收益不年化，不提供样本不足的夏普或未来收益承诺。V1/V2两类报告按其真实schema/输入身份消费，新增族仍须明确适配。

金额与净值使用最多512字符的非指数十进制字符串，显示数值超出有限范围或非零值下溢时整份拒绝；百分比派生不可表示时返回null。输入身份包含规范化history、policy、strategy-or-config的SHA256，保留market_manifest_source、capital_source和费用来源。比较中的model差异由report_schema、algorithm_id及policy_sha256表达，费用比较采用预留及来源。单份曲线按自身净值范围缩放；BPC-R5的比较默认同轴累计收益率，净值模式共用人民币金额轴，并明确各自本金及区间；精确原值保留在日期表。

唯一1.1.2报告的history_sha256绑定原值历史、analysis前复权来源/因子/数据、current_view实际版本与historical_model的完整规范对象；其中任一改变进入input比较差异。其他已封存报告族的原字段语义保持。

## BPC-R3 HTTP与比较

新增GET /v1/ui/backtest/archive/{run_id}/performance?receipt_sha256=... 返回nbw-performance-v1；新增GET /v1/ui/backtest/comparison?left_run_id=...&left_receipt_sha256=...&right_run_id=...&right_receipt_sha256=... 返回nbw-comparison-v1。只读，无query以外body；额外/重复参数、非法身份及选择同一运行拒绝。比较结果包含两份完整身份/指标及条件差异，展示窗口、初始本金、输入、策略版本/配置、模型和费用差异；差异保留解释，不自动把异窗口/异输入当成同条件优劣。同一固定报告对刷新或失败时保留上次成功结果及原读取时间；首次读取失败显示重试。切换报告对使用自己的查询结果。成功空结果替换旧结果。schema、输入/字段、中文错误及容量封闭校验。

## BPC-R4 页面与验收

原回测与报告tab保留启动/取消/逐日记录/归档；在已确认归档内展示单份绩效、净值日期表/曲线，选择第二份归档进行并排比较。正常/空/加载/失败/重读及窄屏可用，读取中和失败时保留同查询结果与原时间。页面呈现名称、版本、绩效、曲线、日期和数量等业务结果，内部SHA/算法/请求/实例身份及完整JSON保留在API与诊断资料，页面直接停止渲染。策略目录继续只读名称、简介和版本。当前新运行仅唯一1.1.2；新报告族及模型范围沿[RR112-R7](retained-resonance.md#rr112-r7-app任务与报告)。已封存报告仍按其原schema校验，只呈现业务结果。

主链采用实际原生归档，从固定安装App/生产SPA读取单份及两份报告，与原record/资金字段逐值复算；覆盖两族报告、空/缺失观察、身份变化/原件损坏、超时/容量、错误恢复和资源关闭。独立审查核对数学口径、完成证明、版本与模型差异；源数据、RT/真实券商/生产及完整模块继续各自资格。

## BPC-R5 可视化与日期明细

用户确认采用曲线在左、日期明细在右的浅色紧凑布局；独立回测入口提供主报告与可选对比报告，旧策略回测地址继续可达。指标行呈现总收益、日末最大回撤、期末净值和累计费用，本金及区间清楚可见。来源、费用依据和计算口径折叠。窄屏将日期明细放在曲线下方。

收益率/净值曲线使用真实交易日，悬停展示日期、净值和日收益，支持日期选择、缩放及买卖日标记开关；买入、卖出、多笔采用文字及不同符号。回撤图与主图共用日期轴。对比曲线分别使用各自初始本金、真实日期及原报告净值，缺失保持断线；短报告结束后保留空白。存在本金、区间或模型差异时保留明确提示。

日收益以相邻记录的有效日末净值计算，首记录保留未知；缺失点后的首个有效点同样保留未知，不跨缺口称为单日收益。回撤曲线沿BPC-R2的初始本金及已观察峰值定义。以上派生归只读报告投影，不修改WT金融事实与原报告。

点击某日显示该报告当天的“持仓与盈亏 / 当日交易”。持仓含证券、日末数量、持仓浮盈亏及该证券累计已实现盈亏；后两项取原positions.csv的dynprofit和closeprofit，均注明未扣费用。原WT只记录非零日末持仓，已平仓证券仍在交易列表可查。逐日capture缺失和原持仓文件缺失分别显示未知；有完整当日日末资金及空持仓原件时显示空仓。当天无成交时继续展示当天持仓。价格、成本、市值缺乏原始字段时不推造。

买卖标记、当日及完整交易列表消费同一归档核验后的原生trades.csv；按WT方向/开平解释买卖，保留原时间、价格、数量、费用。原件摘要、完成证明、单次30秒总预算与只读约束保持；新增投影也使用原归档读取owner和完整核验，不复制金融账本。原CSV不适配时只降级该明细，原绩效仍可读；受支持但损坏的原件继续沿原完整性拒绝。

验收覆盖真实403期、不同本金/区间两报告、报告切换、日期光标与日收益、标记开关、点日持仓盈亏/交易、全部交易分页、无成交、空仓、缺失、桌面及手机。数字与原CSV及公开绩效逐项对应；实现后对照已确认设计检查视觉，交付源码身份、制品及截图，生产切换单独授权。

### 日期投影接口

`GET /v1/ui/backtest/archive/{run_id}/visuals?receipt_sha256=...`返回`nbw-visuals-v1`，绑定run、receipt及report摘要。`points`按原记录交易日递增，每点为`[交易日YYYYMMDD, 日收益百分数或null, 日末回撤负百分数或null, 买入笔数, 卖出笔数, 其他笔数]`。`trades_available=false`表示原生成交格式未适配，零笔数不能解释为真实零成交。成交日期计数归各自报告，比较时不借用另一报告数据。

`GET /v1/ui/backtest/archive/{run_id}/ledger?receipt_sha256=...&day=YYYYMMDD&offset=0&limit=50`返回`nbw-ledger-v1`，绑定同一完成身份。day省略查询全部成交，指定day须属于报告真实记录日期。offset为0至65536，limit为1至50，成交CSV最多65536行；CSV单文件展示读取上限8MiB，整份归档核验与原累计读取预算继续生效。响应包含日期、持仓可用性及非零持仓、成交可用性、筛选后总笔数、offset及本页成交。

持仓逐项为交易日、原WT证券代码、日末数量十进制文本、累计已实现盈亏/浮盈亏人民币十进制文本。成交逐项为原行序号、上海交易日、上海分钟时间YYYYMMDDHHmm、证券、买卖或unknown、原多空/开平、原价格/数量/单笔费用十进制文本。原格式未知与受支持格式的损坏分别处理；未知不补零，损坏不绕过准入。LONG OPEN/CLOSE分别为买/卖，SHORT OPEN/CLOSE分别为卖/买，其他组合保留原方向开平与unknown。

选择器中的本金沿已核验performance字段显示；未取得时标记“本金待读取”。报告标题只承担命名，不参与本金推断，报告序号区分同条件记录。精确日期净值原文在折叠日期表保留，图表提示按显示精度格式化。
