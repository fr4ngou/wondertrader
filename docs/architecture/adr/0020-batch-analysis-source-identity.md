# ADR-0020 批量日线的原请求与证券投影

状态：accepted。所有者：WT 行情来源适配层。

## 背景与约束

原行情 SDK 接受证券列表，分析消费方通常按证券组织统计。将一个批次拆成多个虚构 SDK 回包会改变请求数量、来源时间和未知责任；全市场读取同时需要沿原资源额度分片。

## 决定

显式只读 v8 使用原认证运输及 market.market_data 操作的新批量 policy。一个原 SDK 调用对应一个完整原请求/结果/slot；证券投影保留批次引用，消费方共享原执行时点。外部 provider 管理资源分片和持久消费，来源端只负责原线程 SDK 调用及原值解码。原 v7 保持单证券形状。

## 职责与恢复

来源身份、原 UUID、deadline 和 consumed 沿原只读责任回收合同。完整结果先落盘再确认消费，未知只核原 ID。一个 capture 使用同一完整 binding；来源换代后保留旧责任和旧成功包。统计分母与合格日线覆盖分别由消费方记录；复权及日线闭合验证保持原分析职责。

## 生效

唯一功能正文见[批量日线来源](../../specs/qmt-analysis-batch-source.md)。SDK 全股票池、真实小切片、真实全市场、BJ 缓存和生产资格分别验收；元数据准入保持明确的格式资格。
