# 已结清阶段接纳最新经济目标

状态：accepted。所有者：自有数量转换与原生策略宿主。范围：策略目标接续、回测模型复核。

经济目标有有效期，原生实际持仓与未决委托各有事实所有者。完成一次卖出阶段后，旧目标的买入阶段尚未提交；继续要求旧整轮完成，会让过期买入目标挡住最新经济目标。内部阶段序号也不能决定一个计划是否永久停止。

运行宿主沿原数量模块核完整实际观察，在同证券集合、已实际达到全部冻结阶段目标且没有pending时，接纳最新经济目标。卖出完成须使用新的原生观察身份。实际数量未达标、未决或来源不合格时继续原身份，不取消或重发未知委托。每次调用只推进当次观察，阶段序号保留诊断意义。

纯数量模块移除阶段次数停止条件，数学、资金和费用边界继续沿原契约。回测与运行采用同一新模型；回测标识`latest-settled-target-v2`。历史报告按原模型只读复核，保存原失败及原SHA；新结果另行归档。该调整属于自有适配层，WT执行器及框架保持现有已批准版本。

完整行为与验证条件见[NSQ-R3、R5、R6](../../specs/native-strategy-quantity.md)。

v2的previous_status仅在经济代际变化时记录旧冻结phase，其他情况为null；它属于诊断信息，交接资格仍由本次实际观察和outcome决定。v1保留旧目标推进结果的原含义。单次最新目标费用basis同时用于运行和报告复核，避免把两种目标的费用混在同一记录中。
