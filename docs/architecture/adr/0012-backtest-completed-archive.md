# ADR-0012 完成回测原件与重启只读归档

状态：accepted。所有者：策略宿主与观衡业务维护者。补充[ADR-0003](0003-native-runtime-and-business-state.md)，不改变执行/账户事实所有权。

## 背景与约束

NSH已经以独占UUID目录保存冻结请求、安装绑定、唯一NSB报告及WT原生输出。子结果文件在父端进程回收之前产生；单凭目录或结果存在不能证明父端完成。用户需要进程重启后读取已完成实验的冻结配置和报告。

## 决定

复用现NSH原件，不复制报告、不引数据库或新的任务执行状态。持有最终HostResult的业务责任层仅在completed、exit0、非forced、实际reap/join及唯一报告准入成立后发布有界不可变完成receipt。receipt引用原件摘要；它是原父端完成事实的存储证明。内存历史索引由这些证明重建，不能从未证目录补造完成。

执行状态与归档状态分别表达。归档发布失败保留真实执行/回收事实，中文说明重启可读保证尚未建立；在原owner事实仍可达时可显式重试文件归档，禁止重新执行。活跃owner身份和run/cancel语义不变，稳定历史runID只授只读访问。文件容量、路径、版本、原子不覆盖发布、冲突与读取期限由[NBW-R6](../../specs/native-backtest-workspace.md#nbw-r6-已完成回测只读归档)规定。

## 兼容及验收

没有完成receipt的旧目录保留未归档，不自动恢复执行、清理、迁移或推定成功。原配置/报告留在原文件，历史读取复用唯一NSB准入与投影；原生上下文、资金持仓、行情及订单事实不新增副本。业务应用、发行制品与归档根各自保持明确身份；开发制品ZIP工具不承担业务存储。

验收包含重启读取、损坏/链接/容量/期限/并发、落证异常与真实完成事实分离、现configured/V2兼容，以及独立安装/HTTP/中文页面/资源退出。ADR定义职责，实际实现与动态资格分别登记。
