# ADR-0005 显式只读能力与版本绑定

状态：accepted。所有者：接入、架构与运行维护者。

## 决定与原因

终端接入的可调用能力由一个标准库封闭registry拥有，Host准入、工具配对、持久化入口和Agent派发共同调用。每个能力明确operation、scope、policy、参数与结果限制和固定adapter；部署只能从已有能力中显式选择。这样扩展行情/历史/账户时能够保持同一事实，消除各入口独立白名单逐渐分歧。

完整能力profile原字节及版本参与认证来源绑定；新能力或额度语义采用显式新profile版本。每个客户端声明其理解的完整profile，旧版保持严格拒绝未知字段。运输绑定证明通信来源和代际；券商会话、数据覆盖、账户许可和交易资格仍由各自契约证明。

协议编解码、认证HTTP、原ID恢复和结果校验保持单一实现；C++业务门面只选择编译期固定描述，不接请求提供的operation路径、代码或回调。QMT原线程拥有SDK调用和唯一结果finalizer；I/O线程仅运输消息。历史存储、Reader及原生消费继续归WT。

## 代价与运维

能力版本升级需要两端及消费者形成一致候选并分别验收；保持旧安装、配置和数据以供核查。通信Journal用于原请求/结果恢复，不保存资金或持仓账本。容量达到上限停止准入；保留、归档和跨代查询策略另行定义，版本演进不隐含数据清理或透明换代授权。
