# ADR-0030 WT 私有持久化

状态为 proposed。所有者为 WT 执行、策略运行及数据维护者。补充 [ADR-0003](0003-native-runtime-and-business-state.md) 与 [ADR-0009](0009-trade-command-communication-owner.md)。

## 背景

策略分账将每轮带新查询编号的重复回报保存为新记录，运行快照也按巡检节拍整份重写。交易恢复所需的数据、程序安装和可重建输出需要明确的写入与路径约定。

## 决定

采用配置的 D 盘私有运行根。各模块沿现有事实所有权和单写入者规则持久保存，策略经宿主接口扩展自己的状态。策略读取已提交内存视图，可重建快照由后台合并。需要恢复的事实依原生格式或现有 SQLite 事务、WAL 及 checkpoint 保存。委托、成交及归属用稳定身份去重，后继变化和冲突按既有核查规则留证。公开消费者读取原版本化投影。E 盘承载开发、安装和可重建构建文件。

## 后果

变更须提供原始事实、持久提交、读视图发布和重启之间的验证证据。现有 WT 文件和交易库各自沿原 owner 接续，通过停机快照和独立迁移证明验证新位置。实现与验收见[统一规格](../../specs/wt-private-persistence.md)和[迁移方案](../../migration/wt-private-persistence-migration.md)。
