# ADR-0033 柜台当前费用与差额更正

类型：架构决策。状态：accepted。日期：2026-11-24。范围：已启用同账户策略归属的 QMT 成交费用。

## 背景与决策

用户确认按 QMT 当前逐笔费用记账，保留原精度和来源，后继观察变化时按差额更正。QMT 当前回报不具备最终交割单的确认含义，页面和账本分别表达暂记与结算确认。

券商继续拥有外部费用事实，ASA 继续唯一拥有策略现金、原成交分配与费用归属。复用原成交 ID、原收件顺序和 SQLite 事务，不增加费用守护进程、另一份金融账或发单链。查询和回调的同笔费用沿统一入口处理；未携带费用保持未知，明确零费用才按零记账。

费用按该笔成交已固定的实际份额分配，保留来源可表达的最小十进制单位，分配余数沿原 FIFO 稳定分摊，合计等于原收费。本金继续精确到分，费用和费用影响的余额允许分以下精度。内部使用精确有理数及规范有限十进制持久编码，计算不依赖浮点或调用方 Decimal 精度。

同一费用观察重复到达不重复扣款。后继暂记观察只按原持久收件顺序推进；旧观察重放仅核原证明，不能覆盖新费用。原成交数量、价格、金额、方向和归属冲突继续拒绝。费用最终确认须有独立的最终结算依据；后到的暂记值不能覆盖最终确认。

每次费用变化在同一原账事务内原子更新原成交的当前费用、相关策略余额、整组已付费用和账户本地调整。中断前未提交则整体回滚，提交后重放沿原观察身份幂等。资金、费用上界和未知委托预留继续校验；不得以费用更正释放结果未知的订单责任。

## 迁移与验收

后继账本版本沿原账户和账本身份，在正常停止、备份、单一写入者条件下采用；旧本金、份额、订单、事件与证明保持。副本迁移先核对全部金融事实。旧程序不能读取新费用语义，回退通过已验证的前向兼容程序处理，不用旧备份覆盖新增成交。

覆盖合单部分成交、分以下费用、向上/向下更正、明确零费用、无费用观察、乱序、经济冲突、并发重复、提交前中断和提交后重开。以正式入口和账本副本验证完整接线，再正常发布，生产验收沿自然回报；费用口径和当前是否结算确认同时展示。

详细字段、准入及回归归 [ASA-5](../../specs/account-strategy-allocation.md#asa-5-实际成交终态费用与重启) 唯一维护。
