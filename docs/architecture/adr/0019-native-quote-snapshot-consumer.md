# Native瞬时快照消费责任

状态：accepted。适用范围：Native瞬时报价快照的进程内消费交付边界。

RR3通用外部slot在消费确认前保存原始结果至终端外持久状态；AAR2的Native只读账户扫描采用进程内完整有界值交付。当前报价同为可重新查询的瞬时观察，Native快照owner需要在既有quote ABI内持有原始结果、receipt、全部映射值后确认读取责任。

因此本模块以显式retained Native schema选择该消费边界，Host/源端沿原RR协议。消费确认丢失时Native保留原身份及原结果，原GET/同一消费身份重确认；新业务请求在原责任交接前不会提交。此决定不改变财务事实、金融Journal或未知命令规则，不添加账户数据库/客户端磁盘slot，也不授权跨进程持久恢复。HTTP响应交付和Native消费确认是两个不同阶段。
