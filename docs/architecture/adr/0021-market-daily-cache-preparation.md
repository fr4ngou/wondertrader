# ADR 0021：全市场日线缓存准备沿原HPR

状态：接受。适用[MDP规格](../../specs/qmt-market-daily-preparation.md)。

QMT分析读取采用subscribe=False，日期覆盖取决于终端缓存。缓存更新由原HPR专用能力
承担，读取方继续原v8批量读取和持久消费；观衡消费结果包。

HPR显式v3能力仅扩六位.SH/.SZ/.BJ证券格式，不更换下载SDK、身份、队列、截止、
结果或回收语义。旧v1/v2保持原市场准入。格式、SDK实际支持和数据覆盖分别核定。
官方内置SDK下载按单证券执行，外部workflow编排原调用，不建立第二个历史服务。

每项下载原slot先保存请求及截止，原完整结果先保存再消费；未知沿原ID继续查询。
工作流文件索引这些原事实，通信Journal仍归Host。外部多客户端分别持有运输，QMT SDK
仍在原策略线程和原timer执行。完成捕获保持原批次时间及none/front来源引用。

完整读取覆盖、复权与共同闭合基准由消费方依据实际原始结果核实。缓存尾日不同保留事实，
不自动推断停牌、上市或数据缺失，也不以合成SDK结果填真实指标。
