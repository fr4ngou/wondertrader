# ADR-0018 已确认只读责任的有界回收

类型：长期职责决策。状态：accepted。适用范围：独立只读和历史缓存准备通信。规格见[有界回收](../../specs/qmt-read-retirement.md)。

完成结果分别由 Host 的原通信 Journal 和终端外消费者持有；运输 ACK 证明 Host 收到并持久保存，消费者 consumed ACK 证明调用方持久保存完整原结果。两者事实分开表达。有限容量由仍承担恢复责任的请求占用，确定完成且消费确认、原票据失效后可回收；执行中和未知责任继续保留原身份。

永久任意 UUID 去重需要永久 tombstone。显式回收模式使用截止、Host epoch 和完整原内容绑定 UUID，回收后同一 ID 无法被改造成有效新命令。旧默认模式保留原语义。Host/Source 重启只核原 ID；读取不存在或票据结束不授未执行，不自动重发。

金融订单与撤单的恢复责任继续由原交易 Journal 与 WT 拥有，本决策不扩大其清理或自动重试权限。QMT 内只新增内存责任交接，SDK 继续原线程单 timer；文件持久化和 HTTP 全在终端外。
