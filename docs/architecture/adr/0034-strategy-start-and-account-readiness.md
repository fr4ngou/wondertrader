# ADR-0034 策略启动与账户交易资格分开

状态：accepted；实现、回归及生产生效分别验收。范围：共享账户的 OriginalLive、Retained 策略初始化与恢复。

## 背景

收盘后券商更新可卖数量，内部按交易日保存的 T+1 份额可能稍后才结转。原实现把账户观察等待转换成策略 INIT 异常，导致整个 Native 及其他策略退出。账户观察缺失、陈旧、持仓不符和冻结待核也有同一问题。

## 决定

沿 WT-S01 原 CTA 初始化、主分钟调度和既有 ASA 观察入口推进。初始化从原持久账恢复策略状态、检查模型身份、注册原调度并发布观察；账户暂未核同不阻止这组动作。初始化只镜像已有策略状态，不宣布目标、不下单、不改变原资金和归属数量。

账户完整性、新鲜度、数量和冻结校验继续由原 `observe_context` 负责。返回等待原因时，策略发布该固定原因并停止本轮目标推进；下一次原调度重新核对，合格后自然继续。旧委托与未知命令继续归原执行 owner。采用恢复状态前仍校验账户身份、单一写入者、安装/配置真实性、账本完整性和业务状态模型；不能读取的原持久状态不能被空状态替代。

券商可卖是外部上限，内部 T+1 可卖是各归属的资格。内部可卖合计扣已证明冻结后须非负且不超过券商可卖；券商较高不提前增加内部资格，券商较低则等待核对。本决定不改变结算日、真实持仓和卖出授权。

## 验证

两类策略覆盖账户未知、陈旧、可卖/总量差异及冻结待核时 INIT 成功、状态保留、零新目标；连续调度仍等待，来源恢复后无需重启继续。损坏状态及模型身份冲突继续拒绝。分账覆盖收盘可卖增加不解锁内部 T+1、次交易日正常结转，以及券商可卖减少保留核对。

原生接账仍需当前交易通道完成登录及原 O/P/A 恢复核查；连接生命周期与未知副作用由原 Host 负责，本次不改通信恢复协议。初始化已失败的现场沿 EFR-20 的原状态、原退出和零执行队列证据接续。
