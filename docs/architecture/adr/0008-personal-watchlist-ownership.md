# ADR-0008 个人观察自选由独立应用拥有

状态：accepted。所有者：业务接口维护者。补充ADR-0003；不改变策略、行情及账户事实归属。

个人观察自选记录操作者主动关注的证券及顺序，独立应用拥有其唯一保存入口。WT策略userdata随策略上下文和策略名持有；行情订阅承担接收职责。选用应用内小型偏好文件，可在未启动策略与未连接行情时编辑，同时承担单写者、原子替换和重启读取的维护成本。

策略交易范围继续由策略配置及原生运行上下文拥有。添加或移除个人自选只改变观察偏好；读取行情由用户另一次查看动作触发。数据源、券商账户、委托、持仓、目标与许可分别保持现有owner。浏览器缓存为展示副本，服务端文件保存完整列表及自身版本；应用不增加行情、账户或订单数据库。

[原生能力核实](../../migration/personal-watchlist-native-reuse.md)说明已核接缝与静态范围；[个人观察规格](../../specs/personal-watchlist.md)定义接口、并发、故障和兼容。旧未挂载客户端的审计字段退出新接口，旧源码不构成当前运行依赖。单根单操作者先行；多用户、多列表或策略范围联动需另立契约及事实归属。实现、正式安装与真实保存/重启/中文页面分别验收；设计接受与实现、运行资格分别登记。

个人偏好锁通过CreateFileW share_mode=0在单次OS动作中创建并独占固定锁文件，首次初始化权与锁所有权同时确定；应用保留handle到descriptor再到借用stream的明确所有权。既有StrategyHost锁不作公共抽取或改动。路径准入同时核原盘符与解析后目标的本地目录及实际drive类型。此实现仍按规格取得Windows并发、安装与实际用户链证据。
