# ADR-0002 独立行情接口与业务发行边界

状态：accepted。类型：架构决策。

观衡研究、策略、组合、Bridge、Console 和运维具有自己的业务状态与发布节奏；原生交易底座也具有自己的 ABI 和数据生命周期。跨进程调用以版本化服务接口为边界，业务服务使用公开 DTO，底座拥有原生资源与来源适配。

决定：底座提供薄的版本化行情服务；观衡作为独立客户端消费来源、资格、历史、缺口准备及快照。双方分别发行和回滚，版本兼容检查先于业务使用。私有业务核心和部署配置保留独立受管归属，开发用外部源码逐文件身份校验不构成生产依赖方案。交易权限与账户事实继续遵循[ADR-0001](0001-execution-fact-ownership.md)。

结果：原生 ABI 变化由服务内部吸收，外部接口破坏性变化需要新主版本和消费者验收。服务故障投影为明确 unavailable，观衡保留自己的业务状态和只读诊断。新增服务带来独立健康检查、版本、认证和恢复的运维职责，发布手册与模块文档随接口实现维护。
