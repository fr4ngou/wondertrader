# ADR-0013 QMT连接生命周期

状态：accepted。范围：终端外Host和受限只读Agent的持续等待、断连及重新认证；交易恢复另按原通信契约验收。

## 决策

连接包拥有券商通信生命周期。系统统一入口负责启动Host；Host作为同机独立进程运行，终端内保持共享内存通信。常驻管理器组合原单连接实现，不重写SDK适配、WT持仓、执行算法或金融事实。业务请求仍有截止，等待券商登录可以持续。

每个内核对象、线程和Journal都有原owner。恢复遵循停止旧准入、确认原调用/线程收束及资源关闭、创建新代、重新认证的顺序。旧owner关闭不确定时停止恢复并保留诊断；认证、配置和存储错误要求处理原因。QMT原线程只推进内存状态和已允许的SDK读取，I/O原线程释放自身映射。

旧请求的身份和终态保留在原通信Journal，新代际不自动重放旧委托。运输连接成功只授通信可用，真实账户、数据和交易各沿自身状态验证。常驻恢复通过独立显式入口启用，既有单连接模式保持默认。

## 后果与验证

用户日常启动无需手动协调Host和策略的连接窗口。代价是两端均需管理恢复状态，并验证并发退出、旧代隔离和资源收束。原生能力依据及逐条验收见[QSW-R20](../../specs/qmt-shm-wt-binding.md#qsw-r20-常驻连接与系统统一启动)。合成验证、实际QMT和登录自动启动分别取得证据。
