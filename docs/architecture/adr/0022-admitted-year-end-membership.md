# ADR-0022 年末成员事实与财报更新分责

状态：accepted。所有者：市场观察来源模块。替代关系：补充 ADR-0015 的来源事实边界。

## 背景与约束

年末证券成员与随后披露、修订的财报具有不同时间语义。财报刷新若每次用当前名单重新构造旧年份，会改变已准入的历史成员，也会让旧年份受本次取数日期的名单覆盖限制。

## 候选与决定

采用已准入年末成员事实，按原 Basic、北交所名单及退出公告的内容身份核同成员集合、版本和原核验日；财报来源继续获取新披露与修订值。首次或缺失年份沿原完整建池路径生成新事实。当前资格配置可撤回或修正旧资格，已知事实冲突时停止采用并保留原结果。

## 职责与兼容性

`source.financial_<scope>_universe`持有年末成员及原件版本；`financial_universe`核同和提供成员，`financial_source`获取财报并调用原财务计算。普通报表更新保留旧成员行及其出处；历史成员更正沿原完整校验与CAS采用新版本。原公式、币种、披露日期、缺值、预算和持久格式保持。

## 验证与生效

实现和准入依据见[独立市场观察规格](../../specs/independent-market-observation.md)的年末事实复用条款。覆盖原件一致、缺年份、当前配置撤回、混合年份和失败保旧；各次运行及安装资格登记在[证据索引](../../evidence/README.md)。历史首次可得时间继续未知。
