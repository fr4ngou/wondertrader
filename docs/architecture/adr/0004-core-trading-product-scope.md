# ADR-0004 核心交易产品范围

状态：accepted。所有者：产品、架构和业务维护者。依据：用户于2026-10-22明确要求Grafana、新闻、研究的功能及界面均不进入WonderTrader。本决定替代此前“完整观衡迁入”中对应部分；其他事实所有权和原生复用原则保持。

## 决定

WonderTrader仓库与发行物不包含Grafana服务、大盘、iframe/Viewer接入、Grafana专属凭据与发布门禁。系统保留必要健康检查、运行日志、故障定位和资源回收信息。

新闻与研究服务、自动采集/发现、正文与研报、多角色/AI研究编排、评分校准、人物/社交资料、研究证据任务及其页面、API调用和专属依赖退出迁入与验收范围。清理新仓库已复制的相关实现，不保留可被产品启动或导入的“禁用版”服务。旧工程、用户已有数据和冻结审查原件保留历史归属，不因本决定改写或删除。

保留行情、策略、回测、账户、风险与交易执行、配置和必要运维能力。ETF份额、融资和成交热度等策略必需辅助事实沿策略数据契约处理，不借机保留整套研究服务。AI策略如缺少所需合格外部事实则明确不可用，不合成研究结果或降低交易准入。独立市场观察与其只读行情/宏观指标按原范围维护，已删除的新闻研报功能不通过该入口重新引入。

## 实施与验收

同步产品范围、方案、功能规格与目标清单，撤销对应迁入和发布完成条件。新产品导航、深链、服务能力与接口不得宣称新闻/研究/Grafana“正在接通”。清理专属源码、测试、资产与构建依赖；混合文件按实际调用链拆除对应部分，保留交易与行情共享职责。运行图与安装包不加载已退役模块。

验收涵盖源代码/依赖清点、类型与构建、发行物检查、旧链接退出、行情/账户/策略回测正常及异常恢复。移除产品功能不授权停止旧生产服务或删除历史数据。后续重新引入须由新的明确需求修订本决定。
