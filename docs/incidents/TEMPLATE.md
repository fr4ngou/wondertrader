# 日期与故障主题

状态：investigating / contained / recovering / resolved。等级、环境、协调人及影响范围：待填写。

## 症状与保护动作

记录用户症状、首次发现、影响、已采取动作、权限范围和停止条件。

## 证据与根因

标明实际代码/部署/配置身份，沿触发链、状态变化、依赖和事实所有者说明原因及促成条件；列出证据、假设与待核实条件。核对设计约束、输入校验、测试及监控中的缺口，以及其他入口与调用者的同类风险。

## 时间线与修复

记录关键观察、处置、修复、原触发条件回归和授权，关联修复前后结果及受影响调用链。调试细节链接临时工作记录，正文保留有效发现。

## 恢复与验真

记录真实入口、数据、未完成工作、未知副作用、回报覆盖及恢复后的观察，说明关闭依据。

## 后续动作

列出预防事项、所有者、优先级、状态、可验证的完成条件和关联规格/发布/证据；修复关闭与后续预防事项分别跟踪。通用规则链接所属唯一正文；更正原结论时链接后继记录。
