# 观衡前端开源参考

用于查找工作台布局、后台交互和金融图表的上游实例。新增依赖或复用源码前，核对采用版本的许可证、归属要求及项目已有实现。

| 项目 | 在观衡可参考的内容 | 上游许可 |
| --- | --- | --- |
| [FreqUI](https://github.com/freqtrade/frequi) | Vue 与 TypeScript 的量化工作台。参考交易与观察场景中的导航、图表和状态组织。 | GPL-3.0 |
| [Dockview](https://github.com/dockview/dockview) | 观衡现有停靠布局。参考拖拽分屏、可调整大小的组和布局序列化。商业扩展有独立许可。 | 核心 MIT |
| [FlexLayout](https://github.com/caplin/FlexLayout) | React 停靠布局，参考 JSON 布局模型、分组和标签管理。 | MIT |
| [shadcn-admin](https://github.com/satnaing/shadcn-admin) | Vite 后台界面的导航、工具栏、表格和筛选。 | MIT |
| [next-shadcn-dashboard-starter](https://github.com/Kiranism/next-shadcn-dashboard-starter) | Next.js 后台外壳，参考导航、响应式状态和表单。 | MIT |
| [KLineChart](https://github.com/klinecharts/KLineChart) | K 线、指标、画线和覆盖物，适合比较 A 股及期货行情的操作方式。 | Apache-2.0 |
| [Lightweight Charts](https://github.com/tradingview/lightweight-charts) | 金融时序、行情与时间轴交互。业务指标由数据和计算层提供。 | Apache-2.0 |
| [Apache ECharts](https://github.com/apache/echarts) | 观衡市场观察现有图表库。适合双轴因子曲线、事件标记、资金曲线和热力图。 | Apache-2.0 |
