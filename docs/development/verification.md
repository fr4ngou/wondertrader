# 验证与证据规范

数据/策略主路径验证覆盖实际消费者的必需字段、逐角色非空覆盖、知晓时间和信号/不交易原因。合法空值及正常返回仍核业务影响；其他角色有成交或报告可生成时，也核依赖不同的分支。运行故障检查持久日志、失败状态及源请求，确认实际落盘与首错可定位后再判断无异常。

类型：长期规范。适用范围：开发验证、评审、运行资格和发布验收。

## 按影响选择验证

| 变化 | 必要验证 |
|---|---|
| 文档或注释 | 链接/索引、术语、源码依据、行为说明与任务范围 |
| 纯计算与数据转换 | 可人工核算样本、精度/单位、边界值、异常输入 |
| 公共接口与接入 | 生产者/消费者契约、版本、错误、线程与生命周期 |
| 状态、持久化、交易副作用 | 重复/乱序、重启、持久化前后失败窗口、未知结果和恢复 |
| 并发与容量 | 竞争、背压、满额、取消、超时、退出与资源释放 |
| 回测与策略 | 冻结输入、时钟、预热、未来数据、交易规则及模型限制 |
| 用户入口与部署 | 正常、空、异常、恢复、核心数据、关键操作和实际部署身份 |

修复的回归验证重现原根因条件，并核对受影响链路。测试断言可观察业务结果，不依赖对实现步骤的机械复制。低影响可逆修改按实际风险检查，避免无收益的测试膨胀。

测试分层、原生入口及系统 E2E 场景见[测试手册](../runbooks/testing.md)。测试代码存在、测试框架名称和模拟组件存在分别记录，实际通过结论由对应运行及断言证明。

## 副作用与恢复

隔离环境使用能独立记录实际副作用的替身，区分“请求可能已执行”与“有证据确认未执行”。在消息收发、持久受理、原生调用、结果保存和回报确认前后注入适用故障，核对实际调用数和事实连续性。

测试工具、模拟账户、服务商测试环境和真实账户分别登记。真实交易及权限变化以明确授权覆盖的账户、动作、范围和停止条件执行。

## 证据有效性

记录源码身份（有未提交差异时含文件摘要）、规格、依赖、数据、配置、环境和命令/步骤。标明退出码、实际观察、通过/失败/未执行以及限制。

只复用输入仍匹配的既有证据，并说明适用范围；新增变化、失败或未解决疑点才扩大或重复验证。编译、单测、契约、实际终端及生产用户入口各自证明对应层级。

本地文档工具检查只覆盖其声明的静态范围。构建成功、进程健康和路由返回分别作为中间证据，功能完成还需对应业务调用链正常。

## 私有资料与工具输出

含私有配置的生成脚本、启动入口、日志和命令行整体按私有制品处理。诊断先定义允许输出的字段名、类型、枚举或去敏计数，再在读取侧构造新对象输出。提取生成脚本字段采用静态读取与结构解析，避免执行或import入口产生服务、环境或凭证副作用。源码与配置在同一行时，按行匹配仍可能携带完整凭证；文件过滤、长度截断或调用标题不能替代结构化白名单。未知字段和值保留在受控运行环境，工具结果及会话记录同样属于信息输出边界。

认证资料误输出时立即停止该读取方式，通知维护者并登记字段级影响、记录位置及传播动作；丢弃已知私有内存引用。后续不复述值、不复制原文、不通过再次打印验证是否泄漏。凭证轮换、撤销、重新配对及运行服务变更沿明确授权处理；工具记录的已发生暴露与本地文件清理分别说明。

## 审查与交付

审查围绕最终规格及源码身份，记录发现、严重程度、处理和复验结果。任务完成报告说明实际行为、验证结果和未覆盖范围；详情使用[证据模板](../evidence/TEMPLATE.md)保存。
