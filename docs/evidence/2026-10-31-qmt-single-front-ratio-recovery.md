# 单证券等比复权来源恢复

类型：真实来源故障与恢复证据。状态：单证券恢复已验证。范围：002605.SZ（姚记科技）、2026-07-01 至 2026-10-30 的 82 个日线日期；账户查询、下单和撤单均为零。全池原件继续保留，系统交易资格沿各自证据核实。

## 根因及影响

原全池捕获共 5576 个证券：`none` 全部 observed，`front_ratio` 5575 个 observed，002605.SZ 为 `source_value_invalid`。官方本机 API 独立复读该票，原始 82 日日线正常，等比前/后复权的全部 OHLC 为 NaN，差额复权可读取。原适配器在首日 2026-07-01 的 open 检测到非有限值后拒绝该证券，保留其余证券结果。

原缓存实际只覆盖 2024-08-12 至 2026-10-30 的 536 条正价格记录。该股票上市日为 2011-08-05；15 个除权事件中，11 个系数为负零、2014-09-15 的系数为 NaN，另 3 个为正有限值。前 12 个事件所需的前收盘都早于缓存范围。该来源缺少早期日线时生成了无效的等比系数；当前窗口原始价格仍完整，等比复权由此失败。

根因通过单证券补齐前后的真实结果确认。SDK 后端的具体零值替代算法未提供源码，其内部实现保留未知。外部官方 `getMarketData` 与内置 `get_market_data_ex` 的可用参数不同；本次坏值复现与恢复采用外部原始价格，加原 DAT 时间，输入未修改的正式 DailyBatchAdapter 核验。新内部 SHM 原始 Frame 没有另行捕获。

## 正确处理与结果

Root 复用原已认证 HPR，分别补 2011-08-05—2021-08-04（含首尾 3653 天）和 2021-08-05—2026-10-30（1913 天），符合原接口 3660 天上限。首次 15 年请求在派发前被参数校验拒绝；分段观察一度返回 pending，随后只查询各原 ID 取得终态，保留全部失败记录。原有 Host、权限、策略和协议保持。

补齐后缓存有 3536 条正价格记录，起点恢复至上市日。原 536 条记录的字节 0—43、52—63 保持，变化仅在 44—51；这些未公开字段保留原字节观察，不另赋产品语义。原窗口 82 日的六个数值字段逐值不变。新的 `front_ratio` 82 日 OHLC 均有限且为正，两种模式均通过正式 DailyBatchAdapter。15 个系数全部变为正有限数，现金红利、送转、配股等前六个事件字段保持原值。

15 个系数都可由新覆盖的事件前收盘与分位除权参考价核对。例如 2014-09-15：前收盘 33.07，转增比例 1，参考价 16.535 取至 16.54，系数为 `33.07/16.54=1.9993954050785974`。2020-06-18：前收盘 35.63，现金红利约 0.4017，参考价 35.2283 取至 35.23，系数为 `1.0113539596934433`。初次核对器直接使用未舍入参考价，报告这两项不匹配；该报告保留，后继核对器同时记录理论值、分位值及供应商原系数。此计算仅解释来源，业务数据继续使用官方原价格和原系数。[深交所除权参考价说明](https://www.szse.cn/www/investor/knowledge/t20181017_555756.html)提供公式依据；本机 API 原回包与缓存提供本次具体值。

产品源码、价格算法和 WT 框架均未修改。原 5576 捕获文件保持，新单证券观察显式作为后继提供，供消费者按其来源时间及修订身份采用。
