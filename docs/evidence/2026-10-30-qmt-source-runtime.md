## 根因与实现

原实际失败的唯一请求、绑定、运输代际严格相同。Host 原接收期限先触发，来源随后读到关闭，券商 SDK 调用为零。原实现依赖后台 Python 线程持续推进运输；内置 QMT 官方使用须知说明策略线程限制。受控稀疏 worker 的确定性回归 `red002` 重现已派发请求的 Host-first 超时与 SDK0。具体 QMT 内部 GIL 和公平性机制仍为 unknown。

显式 `strategy_tick` 使用原同一 Context/timer，以 100 毫秒推进原 Framer、Session、ControlPeer、队列及四个来源 owner。缺少帧或 ACK 时返回，原绝对期限跨回调保留；来源创建零运输线程。默认 thread 和 v1 配对保持，显式生命周期由 v2 材料绑定。原 wire、认证、业务身份、Journal 和未知不重发语义保持。
