# 2026-11-04 Host首次故障诊断

类型：验证记录。结果：pass（限定诊断切片）；关联[QSW-R20.9](../specs/qmt-shm-wt-binding.md#r209-host首次故障诊断)。

## 修改与输入身份

`paired_control.py`原先把常驻服务的全部失败统一映射为`runtime_failed`，关闭收据保留业务结果却缺少内部失败分类；`read_service.py`的退休异常同样缺少步骤和原截止剩余时间。此次仅补首次故障纯值快照及独立`failure-diagnostic.json`，保持ready/closed协议、原错误、清理与截止。

两份修改前源码SHA分别为`42515e2ae5928e98c1f8301a6eafbd8ced3d57382fad102d03d2c9f70557ca7e`和`3d06031ccfbb96fd4e38bde770a885647a9804f0c1ca131706861890840f892a`，与目标Host已安装两文件精确一致。对应修改后SHA及两文件原件/候选、源码diff、比较后替换清单、复验脚本和模块收据位于受控QA目录`continuous-runtime/host-failure-diagnostic-cas/`。CAS仅含这两份源码，其余模块和依赖保持目标安装版本。

首次快照在`runtime_failed`映射前冻结。诊断文件在原关闭结果和最后截止检查完成后独占原子发布，使诊断I/O失败或晚回无法改变原关闭结论。首次业务失败与首次退休异常分别保留；未知字符串和异常类只输出`other`。
