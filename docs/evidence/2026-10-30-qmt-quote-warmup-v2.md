# 全市场行情冷初始化与连续流

日期：2026-10-30。规格：[QST9](../specs/qmt-quote-stream.md#qst9-显式冷初始化与在线持续流v2)。本页登记自有 QST 适配层与合成来源验收，真实现场结果由执行该轮操作的主会话另行登记。

## 根因与正确实现

原 v1 在冷快照开始时就打开在线 FIFO。原同步 Writer 为新证券首次建立映射较慢；冷初始化期间持续到来的全市场回调会占用在线队列，容量耗尽可撤销本代并重建同一冷快照前缀。确定性模型沿原安装的 Agent、每秒 6,982 证券、每 200 证券冷消费 1.8 秒及原 65,536 队列重现：10.8 模型秒发生溢出，仅交付 1,200 个快照证券，心跳为 0。该模型证明失效结构；旧真实轮次缺少首断开证据，其直接触发原因继续为 unknown。

显式 `qmt.quote-stream.v2` 把原离线 latest 阶段保留到冷初始化实际完成。源沿 `min(200, max_batch)` 切片；Host 在同一接收 owner 同步消费后核对实际证券集合，并沿原已认证 Session 确认。源随后在原锁内取得最新快照并打开原 FIFO。在线大帧由 Host 切成原 Native 每次最多 200 条。原证券集合、数值、分钟算法、Writer、MAC/seq/ACK、帧/队列容量和各业务/运输截止保持。

初始化窗口保存每证券最新值。连续增量资格从确认后的原子切换点开始；该窗口的首分钟和逐 tick 连续性需要单独核查。在线受理的增量继续逐条排队；溢出撤代、部分 Native 消费失败停流且保留部分效果、不重放整帧。

两轮都使用实际 Python 3.6.8、Windows SHM、正式单正文四源 owner、一个原 timer/一次 QST 订阅、六个 WT owner、原 NAP 和独立 App。初始化期间持续每秒全市场更新，后续在线更新全部发送并由 Native 消费；连接代际为 1，溢出为 0，最终在线队列为 0，心跳已收到。源端禁止文件/网络入口计数为 0，运输工作线程为 0，下单/撤单为 0。

每轮独立观衡读取原发布、页面 HTTP 突发读取不增加对应因果窗口的来源查询，停止 App 后 WT 继续发布，停止 WT 后独立 App 保留最后成功数据。四份已保存扫描以关闭后的原通信 Journal immutable 只读审计：260 个事实、120 个 ABI 槽和浮点 IEEE 位全部相等。HPR 快照及既有真实 Reader 五根历史读取通过。此轮没有浏览器人工页面验收。

所有受管源、WT、App 进程正常 exit 0，外层无 forced，进程树为 0，管道 EOF、线程 join 和句柄关闭完整；原件位于各 SDK `RESULT.json` 与外层控制收据。未修改现场采集实例。

## 默认、边界与打包

独审指出合法小批量 v2 的冷切片需同时遵守 profile 容量。原 a7 在 1/2/199 条批量定向回归失败；a8 统一采用 `min(200, max_batch)` 后通过。原 a7 安装/现场准备材料保持原件。最终 `CHECKS-005.json` 与搬迁安装 `CHECKS-006.json` 各 48 项通过，覆盖默认 v1、原运输身份与截止、冷屏障集合、最新快照切换、重复证券在线 FIFO、原生切片和部分消费失败。

`relocation002` 包含 26 成员角色 ZIP，经原冻结 ATI 在新根普通离线安装；`component-relocation001` 包含完整 162 文件原数据组件及覆盖清单。数据组件只替换 Agent profile 合同和 Host receiver 两个 Python 文件，Native、Writer、Reader、服务入口保持原字节；两个包的成员摘要和独立安装结果分别保留。搬迁安装完成定向回归；完整六组件运行直接授 installation002 的已验主链。

## 保留范围

旧真实 v1 轮次只取得 3,200 个不同证券文件，位于排序宇宙前 3,220 名且有 20 个空洞；首次断开的具体因果仍为 unknown。该事实与确定性模型分别记录。新候选的真实 QMT、实际有效证券覆盖、浏览器展示、初始化首分钟完整性、盘中长期持续及自然归档均按各次实际证据授予；合成主链通过不转授这些范围。真实交易、完整交易恢复和生产发布未在本模块验收。
